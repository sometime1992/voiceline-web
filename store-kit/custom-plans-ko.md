# VoiceLine Local59 · 시간·반복과 나의 루틴

## 기본 기준음

처음 사용하는 기준음은 C3 · 1옥타브 도입니다. 이전 기본값 C4로 저장된 기준음은 최초 업데이트에 한 번 C3로 조정합니다. 다른 기준음과 녹음·연습 기록은 유지하며, 이후 사용자가 C4를 다시 선택하면 그대로 보관합니다.

## 각 기능의 시간·반복

기능 제목 옆 **시간·반복**을 누릅니다. 초 단위 숫자를 직접 입력하고 설정을 저장하거나 바로 시작할 수 있습니다. 소수점 한 자리도 지원합니다.

| 기능 | 직접 정하는 시간 |
| --- | --- |
| 피아노·음정 측정 | 진행 시간, 반복 횟수, 반복 사이 쉬기 |
| 음정 연습 | 한 음 길이 또는 연속 왕복 시간, 듣기 전 준비, 들이쉬기, 회차 사이 쉬기, 반복 횟수 |
| 발성 유지·비브라토 | 기준음 듣기, 들이쉬기, 발성, 반복 사이 쉬기와 반복 횟수 |
| 청음 | 시작 준비, 한 음 듣기, 들이쉬기, 응답, 음 사이 쉬기와 반복 횟수 |
| 발성 강약 | 듣기·들이쉬기·전체 발성 시간 또는 각 강약 단계의 시간, 회복과 반복 횟수 |
| 호흡·워밍업 | 시작 준비, 들이쉬기·내쉬기·허밍·쉬기, 세트 수 |
| 메트로놈 | 진행 시간, 반복 횟수, 회복 시간. BPM·박자표는 기존 화면에서 조절 |
| 녹음 | 지정 시간 후 중단·저장. 시간 0은 직접 중단, 한 번에 한 파일로 저장 |

반복 횟수 **0은 무한 반복**입니다. 피아노·음정 측정·메트로놈은 진행 시간 0으로 직접 중단할 때까지 계속 사용할 수도 있습니다. 녹음은 반복 녹음 대신 지정한 시간에 한 파일로 저장합니다.

## 루틴 만들기

1. 메뉴 → **나의 루틴**을 엽니다.
2. 새 루틴을 누르고 이름과 루틴 전체 반복 횟수를 입력합니다. 전체 반복 0은 무한 반복입니다.
3. 연습을 골라 단계 추가를 누릅니다. 같은 연습을 여러 번 넣거나 쉬기 단계를 사이에 넣을 수 있습니다.
4. 단계 제목을 눌러 시간을 편집하고 위로·아래로 버튼으로 순서를 바꿉니다. 음정 연습 패턴, 기준음, 강약 방법과 메트로놈 BPM도 단계별로 정할 수 있습니다.
5. 설정 저장으로 보관하고 루틴 시작으로 순서대로 진행합니다. 한 루틴은 최대 40단계, 최대 50개 루틴을 저장합니다.
6. 저장한 루틴 목록에서 다시 선택해 수정하거나 삭제합니다. 루틴 삭제는 확인을 위해 한 번 더 눌러 완료합니다.

루틴 안의 개별 단계는 다음 단계로 이동할 수 있도록 1회 이상 유한 횟수로 설정합니다. 끝없이 이어지는 연습은 **루틴 전체 무한 반복**으로 구성합니다.

## 실행과 중단

현재 단계·루틴 반복 진행을 화면에서 확인합니다. 기존 시작 버튼으로 전체 진행을 중단합니다. 중단·기능 이동·백그라운드 전환 시 회복 시간과 다음 단계 예약도 취소하며, 다시 열 때 저절로 이어서 시작하지 않습니다. 녹음 중단 시에는 기존 저장 절차를 따릅니다.

루틴과 시간 설정은 이 기기에 저장됩니다. 앱을 삭제하거나 데이터를 초기화하면 내부 자료가 삭제됩니다. 기존 CI 앱은 삭제하지 않고 같은 패키지·서명의 APK로 업데이트하세요. 정식 앱과 CI 앱의 저장 공간은 서로 다릅니다.
