# VoiceLine Local64 · 연습 설정과 나의 루틴

각 기능 제목 옆 **연습 설정**을 누릅니다. 위에서 적용 범위·현재 값·진행 순서·전체/발성 시간을 확인하고 필요한 그룹을 펼칩니다. 각 단계 버튼을 누르면 관련 입력으로 이동합니다.

| 그룹 | 확인·수정하는 값 |
| --- | --- |
| 연습 내용 | 패턴, 기준음, 듣고/바로 따라 부르기, 청음 순서, 박자표 등 |
| 진행 시간·반복 | 준비·듣기·발성·회복 시간과 반복 방식 |
| 소리·측정 | 소리 종류, 음량, 안내음, 음정 허용 범위, 앱 공통 감도 |

접힌 그룹에도 현재 값이 표시됩니다. 기능에 없는 항목은 나오지 않습니다. **설정 저장**은 일반 연습의 기본값을 저장하고, **이 설정으로 시작**은 저장 후 실행합니다. **루틴 · 이 단계만 적용**은 해당 루틴 단계에만 보관하는 값입니다.

## 시간과 종료 방식

- **직접 중단 / 시간 지정**: 피아노·음정 측정·메트로놈·녹음에서 선택합니다. 녹음은 한 번 시작해서 끝날 때까지 한 파일입니다.
- **횟수 지정 / 계속 반복**: 일반 연습의 반복 방식입니다. 루틴의 개별 단계는 횟수를 지정하고 루틴 전체는 계속 반복할 수 있습니다.
- **초 직접 입력 / BPM에 맞추기**: 음정 연습의 각 음 길이를 설정합니다. 연속 슬라이드는 상행·하행을 포함한 왕복 시간을 입력합니다.
- 호흡·회복의 **0초**는 생략입니다. 빈 값, 범위를 벗어난 숫자, 음역 밖 반음 이동과 너무 빠른 세분 조합은 저장 전에 안내합니다.

전체 시간에는 시작 준비·기준음 듣기·호흡·발성·회복을 포함합니다. 발성 시간은 따로 표시합니다. 일반 음정/호흡 연습은 시작 준비가 처음 한 번이며, 루틴은 같은 단계를 반복할 때도 새 세션으로 시작하므로 매번 준비합니다. 마지막 구절 자체의 회복은 포함하고 루틴 전체 종료 뒤의 외부 회복은 제외합니다.

## 기능별 설정

| 기능 | 주요 항목 |
| --- | --- |
| 피아노 | 시작 옥타브, 건반 음량, 종료 방식 |
| 음정 측정 | 건반 시작 옥타브, 종료 방식, 앱 공통 음정 감지 감도 |
| 음정 연습 | 음계/도약/모음/연속 슬라이드, 패턴·기준음·진행 방식, 음 길이·호흡·회복·반복·반음 이동, 소리·음량·허용 범위 |
| 발성 유지 | 기준음, 실제 발성 시간, 기준음 듣기·호흡·반복·회복·음량 |
| 청음 | 고정 방법 또는 음을 직접 지정, 1~20음, 듣기·호흡·응답·음 사이 휴식·반복·회복 |
| 강약 | 같은 음높이에서 선택한 강약 방법, 전체/단계별 시간과 합계, 기준음 음량과 전환 안내음 크기 |
| 비브라토 | 저장되는 기준음, 듣기·호흡·발성·반복·회복·음량. 측정 기준은 설명에서 확인 |
| 호흡·워밍업 | 시작 준비, 들이쉬기→내쉬기→허밍→쉬기의 각 시간, 세트 수와 전환 안내음 |
| 메트로놈 | BPM, 박자표, 박별 강세·보통·묵음, 세분·BPM 기준·강세 묶음, 소리·음량·음소거. 저장한 리듬이 있으면 불러오기 제공 |
| 녹음 | 직접 중단/시간 지정. 저장 공간과 녹음 기록은 기존 화면에서 확인 |
| 루틴의 쉬기 | 쉬는 시간 |

청음에서 **음을 하나씩 직접 지정**을 고르면 번호별 음 카드를 누르고 선택한 한 음만 바꿉니다. 위의 음 순서로 매번 동일하게 진행합니다. 일반 연습에서도 직접 지정 음과 음 수가 앱 재실행 후 복원됩니다.

소리 미리 듣기는 편집 중인 기준음·선택한 소리·음량을 사용합니다. 음량 0%는 끄기입니다. 마이크 감도는 표준·민감·최대의 특징을 비교해 선택하며 앱 공통으로 적용합니다. 루틴 단계별 감도를 별도로 저장하지 않습니다.

## 루틴 만들기

1. **메뉴 → 나의 루틴 → 새 루틴**을 누르고 이름을 입력합니다.
2. 기능을 선택해 **단계 추가**를 누릅니다. 새 단계에는 현재 일반 연습 값이 초기값으로 들어가며 상세 설정이 바로 열립니다.
3. 한 번에 한 단계씩 펼쳐 편집합니다. 접혀 있어도 선택 내용과 전체 시간이 표시됩니다. **이 단계 설정 완료**로 접은 뒤 **루틴 저장**을 눌러 보관합니다.
4. **위로/아래로/단계 삭제**로 구성하고 전체 반복 횟수 또는 계속 반복을 고릅니다. 위에 전체 루틴 시간이 갱신됩니다.
5. **루틴 시작**을 누릅니다. 저장한 설정과 음 순서대로 진행합니다. 완료·중단 후 원래 일반 연습의 기준음·패턴·박자·건반 위치·음량으로 돌아옵니다.

같은 기능도 단계마다 독립적으로 저장합니다. 일반 연습을 나중에 바꿔도 저장된 루틴 값은 유지합니다. 음정 연습의 반음 이동은 그 단계의 반복 횟수에 적용하고, 다음 전체 루틴에서는 처음 기준음부터 진행합니다. 녹음은 루틴 단계로 추가하지 않습니다.

## 아에이오우는 음계 도약

**음정 연습 → 종류: 모음 · 아에이오우**에서 선택합니다. 한 모음으로 전체 음계를 올라갔다 내려온 뒤 다음 모음으로 넘어갑니다.

| 패턴 | 각 모음의 음 순서 |
| --- | --- |
| 5음 음계 왕복 | 도→레→미→파→솔→파→미→레→도 |
| 도미솔 도약 왕복 | 도→미→솔→미→도 |

아→에→이→오→우 전체가 1세트입니다. **진행 시간·반복**에서 한 음 길이·호흡·모음 사이/회차 끝 쉬기·세트 수를 정합니다. 반음 이동은 다음 세트에서 적용합니다. 먼저 듣기는 각 모음마다 듣기→들이쉬기→같은 모음으로 따라 부르기입니다. 각 목표 음을 정해진 시간 유지하며 듣기·호흡·회복은 채점하지 않습니다. 발음 자체와 소리 크기는 판정하지 않습니다.

예: 한 음 1.8초, 처음 들이쉬기 3초, 각 모음 뒤 회복 3초, 먼저 듣기 끄기, 1세트이면 5음 왕복은 전체 99초/발성 81초, 도미솔 왕복은 전체 63초/발성 45초입니다.

## 입력·기록과 업데이트

강약 전환 안내음이 울려도 실제 입력 그래프는 유지하며 오염될 수 있는 구간만 기준 설정과 채점에서 제외합니다. 실제 무음이나 유효한 음정이 없는 구간은 빈 구간으로 둡니다. 새 연습 기록에는 실행 조건을 남깁니다.

설치용은 **2.0.0-local64-ci (79)**, 표시 이름 **VoiceLine**, 패키지 **com.voiceline.app.local18.ci45**입니다. 기존 테스트 앱을 삭제하지 않고 같은 서명의 APK로 업데이트하세요. 정식 구성은 **2.0.0 (78), com.voiceline.app**이며 CI와 저장 공간이 별도입니다. 앱 삭제·데이터 초기화 시 내부 자료도 삭제되므로 필요한 녹음은 먼저 내보냅니다.

Local62의 과거 모음 강약 루틴은 기존 마이그레이션에 따라 음계 왕복으로 옮깁니다. 이름·단계 식별자·기준음·반복은 유지하고 강약 전용 구간 시간은 한 음 1.8초·모음 사이 3초 기준으로 바꿉니다.
