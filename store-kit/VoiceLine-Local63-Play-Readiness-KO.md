# VoiceLine Local63 · 아에이오우 음계 왕복

확인일: 2026-11-02 · 설치 APK **2.0.0-local63-ci (78)** · 정식 구성 **2.0.0 (77)**

아 한 모음으로 낮은 음에서 높은 음까지 올라갔다 내려온 뒤, 에·이·오·우도 각각 같은 음계로 왕복합니다. 음정 연습의 고정 목표음으로 각 음을 유지하며, 모음마다 한 구절을 끝까지 부릅니다.

## 실행 방법

**메뉴 → 음정 연습 → 종류: 음계·도약**에서 선택합니다.

| 패턴 | 각 모음으로 부르는 순서 |
| --- | --- |
| 아에이오우 · 5음 음계 왕복 | 도 → 레 → 미 → 파 → 솔 → 파 → 미 → 레 → 도 |
| 아에이오우 · 도미솔 도약 왕복 | 도 → 미 → 솔 → 미 → 도 |

아 → 숨 고르기 → 에 → 숨 고르기 → 이 → 숨 고르기 → 오 → 숨 고르기 → 우 순서입니다. 다섯 모음이 1세트입니다. 기준음을 바꾸면 같은 간격으로 옮겨 부릅니다. 반음 이동은 다섯 모음을 마친 뒤 다음 세트에 적용합니다.

연습 설정에서 기준음·바로 따라 부르기/먼저 듣고 따라 부르기·소리·음량·허용 음정 범위를 정합니다. 먼저 듣기는 모음마다 듣기 → 들이쉬기 → 따라 부르기로 진행합니다. 시간·반복에서 한 음 길이·들이쉬기·모음 사이 쉬기·세트 수를 저장합니다. 반복 0은 다섯 모음을 계속 반복합니다. 루틴의 음정 연습 단계에도 같은 설정을 독립적으로 저장합니다.

그래프는 각 목표 음을 분리된 가로선으로 표시합니다. 듣기·들이쉬기·쉬기는 채점하지 않습니다. 각 모음의 모든 음에 충분한 발성이 있어야 완료로 인정합니다. 발음 자체와 소리 크기는 판정하지 않습니다.

## 기존 자료

Local62의 잘못된 모음 강약 선택과 해당 루틴은 음계 왕복으로 전환합니다. 이름·단계 식별자·기준음·반복을 유지하며, 강약 전용 19개 시간은 한 음 1.8초·모음 사이 3초 기준으로 변경합니다. 다른 강약 설정·녹음·연습 기록은 유지합니다.

CI 패키지는 **com.voiceline.app.local18.ci45**로 이전과 같습니다. 기존 테스트 앱을 삭제하지 않고 APK로 업데이트합니다. 정식 패키지 **com.voiceline.app**의 저장 공간은 CI와 별도입니다.
