## 자세한 설명

VoiceLine은 내 목소리의 음높이를 보면서 피아노 기준음을 듣고 연습하는 도구입니다. 음정 그래프와 단계별 안내를 따라 연습하고, 녹음으로 다시 들어보세요.

실시간 음정과 피아노
• 감지한 계이름·옥타브·주파수와 목표음의 차이를 확인합니다.
• 터치 피아노로 기준음을 듣고 같은 높이로 따라 불러봅니다. 기본 기준음은 C3 · 1옥타브 도이며 직접 바꿀 수 있습니다.
• 가로·세로 화면을 지원하며 가로 화면에서는 그래프를 숨겨 건반을 넓게 사용할 수 있습니다.

다양한 연습
• 음계·도약과 연속 슬라이드를 목표 그래프에 맞춰 연습합니다.
• 한 음을 안정적으로 유지하거나, 들은 음을 따라 부르는 청음을 연습합니다.
• 발성 전 기준음 듣기와 숨 들이쉬기 안내로 시작할 시점을 확인합니다.

강약 조절과 비브라토
• 기본 4단계, 점점 크게, 점점 작게, 커졌다 작아지기, 강약 반복, 일정하게 유지, 짧게 강조의 7가지 강약 패턴을 제공합니다.
• 강약 발성 시간을 빠르게 선택하거나 직접 입력하고, 강약 단계별 시간과 목표 범위를 조절합니다.
• 비브라토의 중심 음정·흔들림 폭·반복 속도를 참고값으로 확인합니다.

호흡·워밍업과 메트로놈
• 들이쉬기·내쉬기·허밍·쉬기 시간을 정하고 단계 안내에 따라 진행합니다.
• 메트로놈의 BPM, 박자표, 세분 박자와 강세를 조절합니다.

녹음과 나의 기록
• 내 목소리를 녹음하고 재생·구간 이동·이름 변경·삭제를 할 수 있습니다.
• 사용자가 선택한 녹음은 파일로 저장하거나 다른 앱으로 공유할 수 있습니다.
• 녹음과 연습 기록은 기기 내부에 보관됩니다. 앱 삭제나 데이터 초기화 시 내부 기록도 삭제되므로 필요한 녹음은 먼저 내보내세요.

앱의 연습·녹음 기능은 오프라인으로 동작하며, 로그인과 광고가 없습니다. 마이크 소리는 기기에서 분석하고 개발자 서버로 전송하지 않습니다. 외부 개인정보처리방침·문의 페이지를 여는 경우에는 인터넷 연결이 필요합니다.

측정값은 마이크·주변 소음·재생음의 영향을 받는 연습용 참고 정보입니다. 절대 소음도나 성대 건강을 측정하지 않으며 의료적 진단·치료를 제공하지 않습니다. 편안한 음높이와 소리 크기로 연습하세요.

나의 루틴과 직접 시간 설정
• 원하는 연습을 순서대로 추가해 여러 루틴을 저장하고, 순서를 바꾸거나 삭제할 수 있습니다.
• 연습별 기준음과 시간을 정하고 루틴 전체를 횟수 지정 또는 무한 반복합니다.
• 기능별 시간·반복 설정에서 초 단위 값을 직접 입력하고, 강약 조절은 단계별 시간도 조절합니다.

## 이미지 파일 사용 전 확인

- 피처 그래픽은 `feature-graphic.html`을 1024×500으로 렌더링한 불투명 PNG 또는 JPEG를 사용합니다. 이 HTML은 배너 원본이며 실제 앱 스크린샷이 아닙니다.
- 아이콘은 512×512 PNG를 사용하고 최종 파일의 규격·파일 크기를 확인합니다.
- 스크린샷은 최종 앱 또는 Android 에뮬레이터의 실제 화면을 사용합니다. 성공 점수·사용자 수·평가를 만들어 넣지 않습니다.
- 실제 UI에 없는 홍보 문구·광고 배지·순위·의료 효과를 화면 이미지에 추가하지 않습니다.
- 전화기·태블릿 등 지원할 기기 유형에 맞는 규격과 개수를 콘솔에서 확인합니다.
