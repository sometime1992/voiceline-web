# VoiceLine Local64 · 상세 설정 개선과 검증 결과

설치 APK **2.0.0-local64-ci (79)** · 정식 구성 **2.0.0 (78)** · 확인일 2026-11-02

Local63 설정 검토안을 실제 코드·저장 방식·연습 실행 모델과 다시 대조한 뒤 적용했습니다. 현재 앱에서는 **연습 설정 한곳에서 현재 값과 진행 순서를 확인하고, 관련 항목을 펼쳐 편집하는 구조**가 적합하다고 판단했습니다. 일반 연습과 루틴에서 지원하는 각 기능은 같은 편집기를 사용합니다.

## 공통 변경

- 기능 설명과 설정을 구분하고 상세 설정 진입 버튼을 **연습 설정**으로 통일했습니다. 음정·호흡의 별도 상세 설정 버튼은 제거했고, 메트로놈의 박별 강세 바로가기도 공통 편집기를 엽니다.
- 위쪽에 적용 범위, 현재 패턴·기준음·반복, 전체 시간·발성 시간, 실제 진행 순서와 음 순서를 표시합니다. 진행 단계 버튼을 누르면 해당 설정으로 이동합니다.
- **연습 내용 / 진행 시간·반복 / 소리·측정**으로 나누고, 접혀 있어도 현재 값을 요약합니다. 해당 기능에 없는 그룹은 표시하지 않습니다.
- **횟수 지정 / 계속 반복**, **직접 중단 / 시간 지정**, **초 직접 입력 / BPM에 맞추기**를 직접 선택합니다. 호흡·회복 0초는 생략 의미를 안내합니다.
- Android 큰 글자에서도 제목이 닫기 버튼과 겹치지 않도록 제목 줄바꿈과 닫기 버튼의 고정 공간을 확보했습니다.
- 숫자가 비어 있거나 범위를 벗어나면 입력 옆에 이유를 표시하고 저장을 막습니다. 강약 총시간 초과와 음역 밖 반음 이동, 과도한 메트로놈 세분도 검사합니다.
- 소리 미리 듣기는 편집 중인 음과 음량을 사용합니다. 피아노는 내장 샘플을 사용하며 닫기·화면 이동·중단 시 미리 듣기를 취소합니다.

## 아에이오우는 음계 도약

**메뉴 → 음정 연습 → 종류: 모음 · 아에이오우**에서 선택합니다. 한 모음으로 음계 전체를 왕복하고 다음 모음으로 넘어갑니다. 각 음을 따로 유지하는 방식입니다.

| 패턴 | 한 모음으로 부르는 순서 |
| --- | --- |
| 5음 음계 왕복 | 도 → 레 → 미 → 파 → 솔 → 파 → 미 → 레 → 도 |
| 도미솔 도약 왕복 | 도 → 미 → 솔 → 미 → 도 |

아 → 에 → 이 → 오 → 우 전체가 1세트입니다. 반음 이동은 다음 세트에서 적용합니다. 연속 슬라이드는 별도 종류로 남아 있습니다. 듣기·호흡·쉬기는 채점에서 제외하며 발음 자체와 절대 음량은 판정하지 않습니다.

기본 예시에서 한 음 1.8초, 시작 호흡 3초, 각 모음 뒤 회복 3초, 먼저 듣기 끄기, 1세트라면 5음 왕복은 **전체 99초 / 실제 발성 81초**, 도미솔 왕복은 **전체 63초 / 실제 발성 45초**입니다. 마지막 모음 뒤 회복도 실행 시간에 포함합니다.

일반 음정/호흡 연습은 시작 준비를 처음 한 번 적용합니다. 루틴은 기존처럼 단계 반복마다 개별 연습 세션을 시작하므로 시작 준비도 각 반복에 포함합니다. 시간 미리보기는 이 실행 차이를 반영합니다. 루틴의 단계 사이·전체 반복 사이 회복은 포함하고 전체 종료 뒤의 외부 회복은 제외합니다.

## 유지한 동작

큰 피아노 건반과 훈련 그래프의 배치·가로 화면의 반투명 중앙 겹침·세로 화면의 그래프 위/건반 아래 구조를 유지했습니다. 시작/중단 버튼 하나로 동작하며 기존 녹음·연습 기록·루틴과 마이크 입력/채점 경로를 보존합니다. 전환 안내음 구간도 실제 입력 그래프는 유지하고 오염되는 채점만 제외합니다.

CI 패키지 **com.voiceline.app.local18.ci45**, 설치 이름 **VoiceLine**, CI 서명은 기존과 같습니다. 기존 테스트 앱을 삭제하지 않고 APK로 업데이트합니다. 정식 패키지 **com.voiceline.app**의 저장 공간은 CI와 별도입니다.
