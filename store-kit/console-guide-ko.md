# VoiceLine · Play Console 입력 안내

확인일: 2026년 11월 1일. 아래 내용은 현재 Android 앱 구현을 바탕으로 한 입력 초안입니다. 콘솔에 제출하거나 심사 결과를 확인한 문서는 아닙니다. 최종 서명본과 실제 배포 기능을 대조한 뒤 작성하세요.

‘수집 없음’은 마이크에 접근하지 않는다는 뜻이 아닙니다. Google의 데이터 보안 정의에서는 기기 밖으로 전송하지 않는 기기 내 접근·처리가 수집 신고 범위에서 제외됩니다. 사용자가 명시적으로 선택한 공유는 예외가 적용될 수 있습니다. 자동 전송·새 SDK·새 서버 기능을 추가하면 다시 검토해야 합니다.

수집 없음 흐름에서 표시되지 않는 후속 질문에 임의로 답하지 마세요. 앱 서버가 없는 현재 구현에 서버용 데이터 삭제 포털이나 전송 암호화 기능이 있다고 기재하지 않습니다. 개인정보처리방침은 수집 없음과 별개로 필요합니다.

## 심사자용 앱 접근 설명 초안

> VoiceLine은 로그인이나 유료 구독 없이 사용할 수 있습니다. 첫 화면에서 피아노를 연주하거나 메뉴에서 각 연습을 선택할 수 있습니다. 음정 측정·청음·발성 유지·강약·비브라토·녹음 기능은 시작 버튼을 누른 후 마이크 권한을 허용해야 합니다. 호흡·워밍업은 마이크 없이 실행됩니다. 마이크 입력이 없는 테스트 환경에서는 음정 점수나 강약 기준이 생성되지 않을 수 있으며, 앱은 이를 측정 부족으로 표시합니다. 녹음과 기록은 기기에 저장됩니다.

최종 빌드에서 메뉴 이름과 동작을 확인한 뒤 필요한 경우 콘솔의 ‘앱 액세스’ 설명에 사용하세요.

## 제출 순서

1. `listing-ko.json`의 소개 문구와 최종 이미지 파일을 확인합니다.
2. 개인정보처리방침 페이지의 공개 접근과 문의 경로를 확인하고 지원 이메일을 입력합니다.
3. 최종 앱 식별자·업로드 키·서명 AAB를 확인합니다.
4. 내부 테스트에 올리고 사전 출시 보고서와 실기기 확인 결과를 검토합니다.
5. 데이터 보안·광고·앱 접근·대상 연령·콘텐츠 등급·건강 앱 선언을 작성합니다.
6. 해당 개인 계정의 비공개 테스트 조건을 충족한 뒤 프로덕션 액세스를 신청합니다.
