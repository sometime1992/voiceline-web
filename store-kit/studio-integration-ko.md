# 마인드업 스튜디오 연결

VoiceLine Local58은 앱 안의 공개 방침·개발자 문의·개발자 홈페이지 버튼을 마인드업 스튜디오에 연결합니다. 오프라인으로 읽는 방침의 운영자·이메일도 같은 공개 안내에 맞췄습니다.

| 용도 | 주소 |
| --- | --- |
| 홈페이지 | https://mindup-studio.pages.dev/ |
| 개인정보처리방침 | https://mindup-studio.pages.dev/apps/voiceline/privacy.html |
| 고객지원 | https://mindup-studio.pages.dev/support.html?app=voiceline |
| 지원 이메일 | grand4870@gmail.com |

앱 메뉴 → 개인정보처리방침에서 세 버튼을 사용합니다. 외부 페이지는 버튼을 누르면 시스템 브라우저에서 열고, 방침 본문은 앱 안에서 오프라인으로 읽습니다. 앱 인터넷 권한·자동 음성 전송·새 SDK는 추가하지 않습니다.

CI 테스트 앱은 2.0.0-local58-ci (73), 출시 구성은 2.0.0 (72)입니다. 기존 CI 앱에 같은 패키지·서명으로 업데이트합니다. 이 코드 변경만으로 Play Console의 지원·개인정보 주소가 바뀌지는 않으므로 콘솔의 앱별 항목을 별도로 입력합니다.
