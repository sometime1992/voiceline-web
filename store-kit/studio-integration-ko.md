# 마인드업 스튜디오 연결

VoiceLine Local79의 공개 방침·개발자 문의·개발자 홈페이지 버튼은 마인드업 스튜디오에 연결됩니다. 앱 안에서 오프라인으로 읽는 방침과 공개 홈페이지 방침의 운영자·문의 안내를 일치시켰습니다.

| 개인정보처리방침 | https://mindup-studio.pages.dev/apps/voiceline/privacy.html |
| 고객지원 | https://mindup-studio.pages.dev/support.html?app=voiceline#contact |
| 지원 이메일 | grand4870@gmail.com |

개발자 문의는 VoiceLine을 선택한 직접 문의하기 영역으로 이동합니다. 이메일 앱에서 제목과 문의 양식을 준비하고 사용자가 직접 전송합니다. 홈페이지에서 자동으로 문의를 보내거나 접수하지 않습니다. 앱 내부 음성 자료도 자동 첨부하지 않습니다.

CI 테스트 앱은 2.0.0-local79-ci (96), 출시 구성은 2.0.0 (95)입니다. 기존 CI 앱에 같은 패키지·서명으로 업데이트합니다. 이 코드 변경만으로 Play Console의 지원·개인정보 주소가 바뀌지는 않으므로 콘솔의 앱별 항목을 별도로 입력합니다.
