# VoiceLine · 비공개 테스트 운영 안내

확인일: 2026년 11월 1일. 실제 테스터를 모집하거나 초대하지 않았고, 참여·사용·피드백 실적을 생성하지 않았습니다. 아래 표는 운영자가 실제 확인 후 채울 기록 양식입니다.

## 적용 조건

2023년 11월 13일 이후 생성된 개인 개발자 계정에 해당하면, 공개 출시 전 최소 12명이 연속 14일 이상 비공개 테스트 참여 상태를 유지한 뒤 프로덕션 액세스를 신청해야 합니다. 계정에 표시되는 현재 조건을 콘솔에서 확인하세요. 중간에 탈퇴한 뒤 재참여한 사람의 기간을 합산하지 않습니다. 참여 기간은 실제 콘솔의 옵트인 시점을 기준으로 확인합니다.

앱 사용과 피드백도 실제로 진행해야 합니다. 아래 일정은 테스트를 나누기 위한 운영안이며 Google이 매일 정해진 시간만큼 사용하라고 요구한다는 뜻은 아닙니다. 자동으로 날짜를 채우거나, 사용하지 않은 기능의 의견을 대신 작성하거나, 다른 사람의 계정을 가장하지 않습니다.

## 시작 전에

1. 계정·앱 설정, 서명된 AAB와 지원 이메일, 개인정보처리방침을 준비합니다.
2. 비공개 테스트 트랙에서 실제 참여자의 Google 계정 또는 승인한 그룹을 추가합니다. 이 문서에는 이메일을 수집하지 않습니다.
3. 테스트 릴리스를 배포하고 콘솔이 제공하는 실제 참여 링크를 전달합니다. 링크를 열어 참여 동의한 뒤 Google Play에서 앱을 설치하도록 안내합니다.
4. 각 참여자가 참여한 계정과 설치에 사용하는 계정이 같은지, 현재 참여 상태인지 확인합니다.
5. 오류를 받을 문의 경로와 보고 양식을 안내합니다. 녹음 파일이나 개인 정보를 공개로 보내도록 요구하지 않습니다.

## 테스트 운영안

| 기간 | 확인할 기능 | 실제 피드백에 기록할 내용 |
| --- | --- | --- |
| 1~2일 | 설치, VoiceLine 이름, 권한 허용·거절, 개인정보처리방침 | 첫 사용에서 이해하기 어려운 문구·설치/권한 문제 |
| 3~5일 | 피아노, 음정 측정, 가로·세로 회전 | 입력 지연 체감, 계이름·그래프 가독성, 잘리는 화면 |
| 6~8일 | 음정 연습, 발성 유지, 청음 | 준비 호흡과 발성 시작을 구분할 수 있는지 |
| 9~11일 | 강약 패턴·시간, 비브라토, 워밍업, 메트로놈 | 목표·안내음·카운트가 이해되는지, 중단이 정상인지 |
| 12~14일 | 녹음·재생·저장·공유·삭제, 앱 재실행 | 데이터 유지·파일 처리·취소 동작과 다시 발생하는 오류 |

의도한 14일이 지났더라도 신청 직전에 최소 인원과 연속 참여 상태를 다시 확인하세요. 조건을 채운 뒤에도 프로덕션 액세스 신청과 Google의 검토가 필요합니다.

## 프로덕션 액세스 신청 준비

실제 기록을 바탕으로 다음 내용을 정리합니다. 문장 속 숫자와 사례는 확인된 값만 사용하세요.

- 어떤 사용자에게 어떤 방법으로 참여를 요청했는지
- 실제로 테스트한 기능·기기·기간과 참여 정도
- 어떤 피드백을 받았고 무엇을 수정했는지
- 남은 문제와 출시할 수 있다고 판단한 근거

초대 인원만으로 테스트 완료를 표시하지 않습니다. 콘솔의 옵트인 상태·연속 기간·피드백과 수정 기록을 함께 확인한 뒤 신청합니다.
