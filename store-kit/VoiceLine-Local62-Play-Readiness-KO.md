# VoiceLine Local62 · 모음 강약 연습

확인일: 2026-11-02 · 설치 APK 2.0.0-local62-ci (77) · Play 구성 2.0.0 (76)

새 **모음 강약 · 아에이오우** 연습을 추가했습니다. 같은 음높이로 아 → 에 → 이 → 오 → 우를 순서대로 발성하며, 각 모음마다 약하게 기준 잡기 → 점점 크게 → 점점 작게를 진행합니다. 기본은 모음마다 2·3·3초, 모음 사이 들이쉬기 3초로 총 52초(발성 40초 + 모음 사이 호흡 12초)입니다. 시작 전 기준음과 준비 호흡은 별도입니다. 모음마다 다른 개인 기준을 잡고 호흡 구간은 채점하지 않습니다. 시간·반복과 루틴에서 19개 구간의 길이를 직접 저장할 수 있습니다. 모음의 발음 자체는 판정하지 않고 음정·상대 강약을 측정합니다.

강약 전환 안내음 때 측정값을 통째로 비우던 처리를 분리했습니다. 감지된 입력은 점선으로 계속 표시하고, 안내음 구간은 기준 크기와 점수에서 제외합니다. 실제로 감지하지 못한 구간은 그대로 유지합니다. 루틴의 음정 연습에서 **바로 따라 부르기**와 **먼저 듣고 따라 부르기**를 항상 보이는 선택 버튼으로 표시합니다. 단계별 선택을 저장·복원하고, 먼저 듣기는 듣기 → 들이쉬기 → 따라 부르기 순서로 실행합니다. 듣는 구간은 채점하지 않습니다. 먼저 듣기 전 준비 시간은 먼저 듣기를 선택했을 때만 입력합니다. 루틴에 추가한 단계는 상세 설정이 바로 열립니다. 접힌 단계에도 선택한 방법·기준음·시간·반복이 표시됩니다. 음정 연습의 진행 방식과 소리, 청음의 고정 패턴 또는 직접 지정 음, 메트로놈의 박자·세분·강세, 건반 시작 옥타브와 음량 등을 단계별로 저장하고 그대로 실행합니다. 일반 연습 화면의 설정을 나중에 바꿔도 저장한 루틴의 값은 유지하며, 루틴이 끝나면 일반 화면의 설정을 복원합니다. 설치 파일과 기존 업로드 키로 서명한 AAB를 준비했습니다. Play Console 업로드·심사 제출과 실제 휴대폰 검사는 아직 수행하지 않았습니다.

## 현재 앱에 적용한 기능

- **발성 강약 조절 → 연습 방법 → 모음 강약 · 아에이오우**에서 시작합니다. 다섯 모음의 순서·현재 강약 방향·그래프를 안내하고 모음별 약한 소리를 따로 기준으로 잡습니다.
- 시간·반복에서 각 모음의 기준·커지기·작아지기 및 모음 사이 들이쉬기 시간을 입력합니다. 들이쉬기 0초는 생략, 전체 300초 이내이며 반복 0은 무한 반복입니다. 루틴에도 19개 구간과 반복 횟수를 저장합니다.
- 강약 전환 안내음 구간에도 감지된 입력을 보관하고 흐린 점선으로 표시합니다. 안내음 구간은 기준 크기·음정·강약 점수에서 제외하며 실제 무음과 구분합니다. 네이티브/브라우저의 8가지 측정 모드 입력 경로를 함께 검증했습니다.
- 단계 제목의 **상세 설정**을 눌러 수정합니다. 새로 추가한 단계는 자동으로 펼쳐지며 아래의 음 순서·방법 안내에서 실행 내용을 미리 확인합니다.
- 청음은 기존 고정 순서·같은 음·장조 상행/하행·3화음·반음 또는 직접 음 지정으로 구성합니다. 직접 지정한 음은 1번째부터 선택한 순서대로 매번 동일하게 실행합니다.
- 음정 연습의 진행 방식 두 가지를 함께 표시합니다. 각 단계의 선택을 저장하고 재실행해도 유지하며, 먼저 듣는 동안은 채점하지 않습니다.
- 음정 연습은 패턴·기준음·먼저 듣기 여부·초 또는 BPM·가이드 소리/음량·허용 범위·반복 시 반음 이동까지 저장합니다. 음역을 벗어나는 이동은 저장/시작 전에 안내합니다.
- 메트로놈은 박자표·BPM 기준 음표·세분·박별 강세/묵음·소리/음량을 단계별로 정합니다.
- 메뉴는 호흡·워밍업/나의 기록 다음 줄에 나의 루틴/사용법을 나란히 배치합니다.
- 기본 기준음은 C3 · 1옥타브 도입니다. 기존 기본값 C4는 업데이트 시 한 번 조정하며, 다른 기준음과 녹음·연습 기록은 유지합니다. 이후 사용자가 C4를 선택하면 그대로 저장합니다.
- 각 기능 제목 옆 **시간·반복**에서 초 단위와 소수점 한 자리로 시간을 입력합니다. 기준음 듣기·들이쉬기·발성·회복, 음정 연습의 한 음 또는 슬라이드 길이, 청음의 듣기·응답·음 사이 쉬기를 설정할 수 있습니다.
- 연습 반복 횟수 **0은 무한 반복**입니다. 피아노·음정 측정·메트로놈의 진행 시간 0은 직접 중단입니다. 녹음은 시간 0이면 직접 중단, 지정 시간이면 한 파일로 자동 저장하며 반복 녹음은 하지 않습니다.
- 발성 강약은 전체 시간 또는 각 강약 단계의 시간을 직접 정합니다. 호흡·워밍업도 단계별 시간과 세트 수를 입력합니다.
- 메뉴 → **나의 루틴**에서 여러 루틴을 만들고 선택·수정·삭제합니다. 같은 연습을 여러 번 넣고, 쉬기 단계를 삽입하고, 위로·아래로 이동하거나 단계를 삭제합니다.
- 루틴의 단계마다 연습에 필요한 기준음·패턴·시간·횟수를 설정합니다. 개별 단계는 다음 단계로 진행할 수 있는 유한 횟수이며, 전체 루틴은 유한 또는 무한 반복합니다. 최대 50개 루틴, 루틴당 40단계를 저장합니다.
- 실행 중 중단·기능 전환·백그라운드 이동은 예약된 다음 단계와 회복도 취소합니다. 화면 복귀 시 자동으로 다시 시작하지 않습니다. 자세한 사용법은 `custom-plans-ko.md`에 있습니다.
