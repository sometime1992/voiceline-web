## Local58 시간·반복과 루틴

1. 업데이트 후 기본 기준음이 C3 · 1옥 도인지 확인하고, 다른 기준음으로 바꾼 뒤 재실행해 유지되는지 확인합니다.
2. 각 기능의 시간·반복에서 소수점 초 값을 저장하고 실제 재생·발성·들이쉬기·휴식 시간이 맞는지 확인합니다. 강약 조절은 전체 길이와 단계별 길이를 각각 확인합니다.
3. 연습 반복 0으로 시작한 뒤 시작 버튼, 기능 전환, 뒤로 가기, 백그라운드 전환으로 중단하고 소리가 다시 저절로 재생되지 않는지 확인합니다.
4. 서로 다른 이름의 루틴 두 개를 만들고, 같은 연습 추가·쉬기 삽입·순서 이동·단계 삭제·앱 재실행·한 루틴만 삭제를 확인합니다.
5. 루틴 전체 2회 및 0회(무한)로 실행해 단계별 기준음·패턴·시간과 회복을 확인합니다. 개별 단계는 유한 반복, 전체 루틴은 무한 반복이 가능해야 합니다.
6. 녹음 시간 0은 직접 중단, 지정 시간은 자동 저장으로 동작하고 한 번에 한 파일만 생기는지 확인합니다. 기존 녹음·연습 기록이 남아 있는지도 확인합니다.

## Local60 단계별 상세 설정

1. 새 단계를 추가하면 설정이 바로 열리고, 접은 단계에 선택한 패턴·기준음·시간·반복이 표시되는지 확인합니다.
2. 서로 다른 패턴과 기준음의 음정 연습 두 단계를 저장합니다. 일반 연습 설정을 바꾸고 앱을 재시작해도 루틴 값으로 실행되는지 확인합니다.
3. 먼저 듣기/바로 부르기, 초/BPM, 가이드 소리·음량·허용 범위와 반음 이동을 각각 확인합니다. 회복 시간이 한 번만 적용되어야 합니다.
4. 청음의 직접 지정에서 C4→E4 등 원하는 순서를 저장하고 그대로 들리는지 확인합니다. 고정 패턴도 반복 시 같은 순서인지 확인합니다.
5. 메트로놈 5/8, 세분 2, 박별 강세·묵음, 선택한 소리와 음량이 적용되는지 확인합니다.
6. 비브라토 기준음을 다른 옥타브로 지정해 목표 건반이 보이는지 확인합니다. 종료·중단 후 일반 화면의 설정과 음량이 복원되는지 확인합니다.
7. 음역을 벗어나는 반음 이동과 너무 빠른 클릭 조합은 저장 전에 안내하고, 기존 루틴·녹음·기록을 유지하는지 확인합니다.

## Local61 루틴 음정 연습 진행 방식

1. 음정 연습 단계를 추가해 두 진행 방식이 함께 보이고 선택 표시가 구분되는지 확인합니다.
2. 바로 따라 부르기에서는 먼저 듣기 전 준비 입력이 비활성화되고, 발성 전 들이쉬기 후 바로 시작하는지 확인합니다.
3. 다음 단계에는 먼저 듣고 따라 부르기를 선택하고, 준비·듣기·들이쉬기·따라 부르기 순서와 듣는 구간의 미채점을 확인합니다.
4. 저장 후 앱 재실행과 루틴 반복에서도 각 단계에 선택한 방식이 유지되는지 확인합니다.

## Local61 연속 입력과 안내음

1. 강약 안내음 끄기·70%·100%에서 같은 음을 길게 내고 단계 전환 전후의 실제 목소리 표시를 비교합니다. 안내음 구간은 점선과 채점 제외 문구로 구분되어야 합니다.
2. 안내음 구간에 실제로 발성을 멈췄을 때 목소리가 자동으로 채워지지 않는지 확인합니다.
3. 발성 유지·청음·음정 연습·비브라토·음정 측정·녹음에서 작게/크게 낼 때 입력과 실제 무음을 구분하는지 확인합니다. 녹음에는 중간 소리가 빠지지 않아야 합니다.
4. 이어폰과 휴대폰 스피커를 각각 사용해 확인하고, 반복되는 끊김이 있으면 안내음 설정·기준음·발생 시점을 기록합니다.
