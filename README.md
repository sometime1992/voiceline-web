# 보이스라인 (VOICE LINE) — 모바일 보컬 음정 연습 웹앱

첨부된 노래 연습 영상의 **목표 음정(계단형 가이드)과 실제 목소리 피치 트레이스 비교** 방식을 참고해 제작한 독립적인 정적 웹앱입니다.

## 포함 기능
- **자유 측정:** 마이크 입력의 실시간 음정, 음명, 주파수(Hz), 센트(cents) 편차, 그래프
- **음정 따라가기:** 시작음·속도·연습패턴 선택, 3초 준비, 9개(또는 8개) 음정 가이드와 1/3/10회 반복, 실시간 비교, 정확도 집계
- **음역대 측정:** 0.5초 정도 지속된 안정된 음만 최저/최고음으로 채택, 측정 결과 저장
- **기록:** 마지막 측정 음역 및 연습 이력을 브라우저 로컬 저장소에 저장. 초기화/기록 삭제 지원
- **모바일 최적화:** 터치 탭, 반응형 화면, 홈 화면 설치용 PWA 매니페스트 및 오프라인 캐시
- **개인정보:** 마이크 샘플은 기기 내 Web Audio API로 즉시 계산하고 버림. 서버/DB/외부 라이브러리 불필요.

## 빠른 실행

### 1. PC에서
```bash
cd voiceline-web
python -m http.server 8000
```
PC 브라우저로 `http://localhost:8000`에 접속한 뒤 **마이크 켜기** 버튼을 클릭하세요.

### 2. Cloudflare Pages에 배포하기
이 폴더의 모든 파일을 GitHub 저장소 루트에 업로드하세요.
Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git에 저장소를 연결합니다.
- Framework preset: **None**
- Build command: **(비워두기)**
- Build output directory: **`.`** (저장소 루트에 `index.html`이 있는 경우)
- Production branch: main

또는 Cloudflare Pages의 **Direct Upload**로 폴더의 파일을 배포할 수 있습니다. 배포 후 제공되는 `https://...pages.dev` 주소에서 마이크 권한을 허용하세요.

### 3. 스마트폰에서
크롬 또는 삼성 인터넷으로 **HTTPS로 배포된 주소**에 접속 → `마이크 켜기` → 마이크 허용 → 연습. 모바일에서 PC 로컬 IP(`http://192.168...`)로 접근하면 보안 정책으로 마이크 사용이 차단될 수 있습니다. **HTTPS가 필수**입니다.

## 사용 팁과 제한
- 조용한 공간에서 **한 사람의 단일 목소리**를 측정하도록 설계했습니다. 반주가 크거나 여러 소리가 섞이면 오류가 발생할 수 있습니다.
- 기준음 재생은 스피커를 통해 마이크에 들어가 잘못 측정될 수 있으므로 **이어폰을 권장**합니다.
- 피치 검출은 YIN 알고리즘을 사용하며 약 **65–1,100Hz**의 기본주파수를 추정합니다. 무음·잡음·불규칙한 발성은 제외됩니다.
- 음역대 측정은 브라우저의 간이 추정값이며 의학적 판단/음성의학 검사/전문 보컬 평가를 대신하지 않습니다. 목에 무리가 가면 즉시 멈춰 주세요.
- 연습 점수는 목표 음정 **±35센트 내**로 들어온 유효 측정 횟수의 비율이며, 무음 구간은 분모에서 제외합니다. 리듬·음색·성량은 평가하지 않습니다.
- iOS/Android의 브라우저 정책에 따라 백그라운드 이동 시 마이크가 중단됩니다. 웹앱은 화면으로 돌아오면 마이크를 다시 켜야 합니다.
- 기기 내 기록은 브라우저 사이트 데이터 삭제 또는 시크릿 모드 종료 시 사라질 수 있습니다.
- PWA 설치 가능 여부와 설치 안내는 브라우저에 따라 다를 수 있습니다. PWA PNG 아이콘(192/512px)이 포함되어 있습니다.

## 파일 구조

```
index.html            한글 UI
styles.css            어두운 보라색 반응형 테마

sw.js                 PWA 오프라인 캐시
manifest.webmanifest  설치 정보
favicon.svg           웹 파비콘
icon.svg              SVG 앱 아이콘
icon-192.png          PWA 아이콘 192px
icon-512.png          PWA 아이콘 512px
```
