Android 앱 · 기기 내 처리
VoiceLine Android 앱은 마이크 입력을 기기 안에서 분석합니다. 녹음과 연습 기록은 기기에 보관하며, 개발자 서버로 전송하지 않습니다.

1. 적용 범위와 처리하는 정보

이 방침은 VoiceLine Android 앱에 적용됩니다. 앱에는 회원가입이나 로그인, 사용자 프로필 기능이 없습니다.

음정 측정과 발성 연습을 시작하면 마이크 음성을 일시적으로 읽어 음높이·음역·상대적인 소리 크기·비브라토를 기기에서 분석합니다. 녹음 기능을 켜지 않은 실시간 마이크 입력은 녹음 파일로 저장하지 않습니다.

사용자가 녹음을 시작하면 음성 파일과 해당 녹음의 날짜·길이·음정 정보 등을 기기에 저장합니다. 연습 결과에는 날짜·연습 종류·음역·일치율·유효 발성 시간 등 해당 기능의 측정값을 저장합니다. 음량·감도·연습 방법·길이 등의 설정도 기기에 보관합니다.

2. 이용 목적

마이크 입력은 사용자가 요청한 실시간 음정 표시, 목표음과의 비교, 발성 강약·유지·비브라토 연습 및 선택한 녹음에 사용합니다. 기록과 설정은 이전 연습을 확인하고 같은 설정으로 연습하기 위해 사용합니다.

분석은 음악 연습을 돕는 참고값입니다. 절대 음압, 건강 상태 또는 성대 상태를 측정하거나 의료적 진단을 제공하지 않습니다.

3. 서버 전송과 제3자 제공

현재 Android 앱은 인터넷 권한을 요청하지 않으며, 마이크 음성·녹음·연습 기록을 개발자 서버로 전송하지 않습니다. 광고 SDK나 외부 분석 SDK를 연결하지 않았습니다.

사용자가 직접 내보내기 또는 공유를 선택하면 선택한 위치나 다른 앱으로 파일을 전달할 수 있습니다. 이 동작은 사용자의 요청에 따라 이루어지며 자동 공유하지 않습니다. 전달한 뒤의 처리는 사용자가 선택한 앱 또는 저장 서비스의 정책을 따릅니다.

4. 보관 기간과 삭제

실시간 분석에 쓰는 음성 입력은 분석용 메모리에서 일시적으로 처리합니다. 녹음 기능으로 저장한 파일과 연습 기록은 사용자가 삭제하거나 앱 데이터를 초기화·삭제할 때까지 앱 저장 공간에 보관합니다. 저장이 중단된 녹음 일부는 복구를 위해 남을 수 있습니다.

앱의 나의 기록에서 녹음·연습 기록을 삭제할 수 있습니다. Android 설정에서 앱 데이터를 초기화하거나 앱을 삭제하면 앱 내부 자료도 삭제됩니다. 사용자가 다른 위치로 내보낸 파일이나 다른 앱에 공유한 사본은 해당 위치 또는 앱에서 별도로 삭제해야 합니다.

내보내기·공유를 준비할 때 앱 캐시에 임시 파일이 생길 수 있습니다. 이 파일은 캐시 정리 또는 앱 데이터 삭제 대상입니다.

5. 마이크 권한과 선택

마이크가 필요한 기능을 사용자가 시작할 때 Android 마이크 권한을 요청합니다. 권한을 거절하면 마이크 분석과 녹음은 사용할 수 없지만 피아노 연주·메트로놈·안내형 호흡 워밍업 등 마이크가 필요 없는 기능은 사용할 수 있습니다.

Android 설정의 앱 권한에서 언제든 마이크 권한을 변경할 수 있습니다. 앱을 벗어나거나 마이크를 끄면 마이크 활동을 중단하며, 진행 중인 녹음은 저장 절차를 수행합니다.

6. 저장과 보호 조치

녹음과 기록은 앱의 내부 저장 공간을 사용합니다. 앱 자체의 계정 동기화나 클라우드 백업 서비스는 제공하지 않습니다. Android 백업을 비활성화하고 Android 12 이후의 백업·기기 이전 규칙에도 앱 자료를 제외하도록 구성했습니다.

다른 앱에 녹음을 공유할 때는 사용자가 선택한 파일을 읽는 데 필요한 임시 권한을 사용합니다. 다른 위치에 저장·공유한 사본의 접근 권한과 보관은 그 위치 또는 서비스의 설정을 따릅니다.

7. 사용자 선택과 권리 행사

사용자는 마이크 사용을 중단하거나 권한을 해제하고, 앱의 기록 삭제 기능 또는 Android의 앱 데이터 삭제 기능을 사용할 수 있습니다. 삭제하려는 자료는 내보낸 사본과 앱 내부 원본을 구분해 확인해 주세요.

앱에는 계정이 없어 별도의 계정 삭제 절차는 없습니다. 개인정보 처리에 관한 문의는 아래 개발자 문의 경로를 이용할 수 있습니다.

8. 외부 문서와 문의 서비스

공개 방침 페이지나 개발자 문의를 열면 시스템 브라우저 등 외부 앱으로 이동할 수 있습니다. 이러한 웹사이트와 문의 서비스의 접속·계정 정보 처리는 각 서비스의 정책을 따르며, 앱 내부 음성 자료를 자동으로 첨부하지 않습니다.
