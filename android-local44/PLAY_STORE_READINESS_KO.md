# 보이스라인 Google Play 등록 준비 점검

확인일: 2026년 11월 1일 · 대상: Local54 Android 프로젝트

등록 준비는 진행할 수 있습니다. 현재 테스트 APK를 그대로 스토어에 제출할 수 있는 상태는 아닙니다. 출시 서명과 개인정보처리방침, 스토어 자료 및 개발자 콘솔 확인이 남아 있습니다. 콘솔 계정·등록된 패키지·테스터 상태에는 접근하지 않았습니다.

## 코드에서 확인하고 보완한 항목

| 항목 | 현재 상태 | 확인 범위 |
| --- | --- | --- |
| 대상 Android 버전 | compile/target SDK 36 | 2026년 8월 31일부터 신규 앱·업데이트는 API 36 이상 필요. 기존 35에서 수정 |
| 빌드 도구 | AGP 8.10.1 / Gradle 8.11.1 / Java 17 | API 36 지원 조합으로 수정 |
| 출시용 빌드 | `:app:bundleRelease`, `:app:lintRelease` 자동 검사 추가 | 성공 결과는 해당 커밋 Actions의 Release-Readiness 보고서에서 확인. 생성 AAB는 검토용 미서명 파일 |
| Android 16 화면·뒤로 가기 | 기존 시스템 바·키보드 인셋 처리 유지, Android 13+ 콜백 연결 | 실기기에서 회전·제스처 뒤로 가기·키보드 확인 필요 |
| 권한 | 마이크 `RECORD_AUDIO` | 마이크가 필요한 동작을 시작할 때 권한 요청. 마이크는 필수 기기 기능으로 선언하지 않음 |
| 네트워크·광고 | 앱 매니페스트에 INTERNET 권한 없음. 광고·분석 SDK 연결 없음 | 현재 Android 빌드 기준. 웹 배포나 향후 SDK 추가 시 재점검 |
| 녹음·기록 | 기기 내부 저장, 앱 백업 비활성화 | 사용자가 명시적으로 내보내기·공유 가능. 앱 삭제·데이터 초기화 시 내부 기록 삭제 |
| 분석 방식 | 사용하지 않음 | 음정·상대 음량 분석은 기기에서 처리. 절대 음압·성대 건강을 진단하지 않음 |
| 네이티브 라이브러리 | 앱 소스에 자체 `.so` 없음 | 검토 AAB에서 `.so` 부재도 검사. 의존성이 바뀌면 16 KB 페이지 호환성 재확인 |
| 음원 저작권 안내 | 앱 사용법에 Tone.js·@tonejs/piano·Salamander 저작자와 라이선스 표시 | 원본 라이선스 및 포함 자료를 정식 배포 전 최종 확인 |
| 아이콘 | 기존 512×512 RGB PNG, 약 332 KB | 별도 1024×500 피처 그래픽과 실제 앱 스크린샷 준비 필요 |

## 등록 전 반드시 마무리할 항목

1. **정식 앱 식별자와 업로드 서명키**
   - 출시 빌드의 현재 식별자는 `com.voiceline.app`입니다. 콘솔에서 이미 쓰는 식별자가 있다면 먼저 대조해야 합니다.
   - CI 테스트 앱의 식별자는 `com.voiceline.app.local18.ci45`이며 공개 테스트용 서명을 사용합니다. 정식 업로드 키로 재사용하지 않습니다.
   - 소유자가 보관할 전용 업로드 키를 준비하고 Play App Signing을 설정한 뒤 서명된 AAB를 생성해야 합니다. 키를 저장소나 배포 ZIP에 넣지 않습니다.
   - 정식 앱과 현재 CI 앱은 식별자가 달라 데이터가 자동으로 이전되지 않습니다. 기존 사용자는 필요한 녹음을 내보내야 합니다.

2. **개인정보처리방침과 개발자 연락처**
   - 앱 안에는 로컬 처리·저장 안내가 있으나, 공개 개인정보처리방침 URL과 개발자 문의처는 확인되지 않았습니다.
   - 마이크 접근 목적, 기기 내 음정 분석, 녹음·기록 저장, 사용자 주도 내보내기/공유, 삭제·보관 방법, 개발자 문의처를 구체적으로 적어야 합니다.
   - 로그인 없이 열리는 일반 웹페이지로 게시하고 앱과 Play Console에서 접근할 수 있게 연결해야 합니다. PDF만 올리는 방식은 해당 요건을 충족하지 않습니다.

3. **콘솔의 앱 콘텐츠 선언**
   - 데이터 보안, 광고 포함 여부, 앱 접근, 콘텐츠 등급, 대상 연령, 건강 앱 선언을 실제 기능에 맞게 작성합니다.
   - 현재 소스만 보면 서버로 보내는 데이터는 확인되지 않습니다. 기기 내 처리 데이터는 일반적으로 데이터 보안의 ‘수집’에 해당하지 않으며, 사용자 요청에 따른 공유는 예외가 적용될 수 있습니다. 최종 배포본의 모든 SDK·동작을 기준으로 답해야 합니다.
   - 로그인 기능이 없어 계정 삭제 흐름은 현재 앱에는 없습니다. 기록·녹음 삭제 기능은 제공됩니다.
   - 발성 연습·호흡 타이머가 있는 만큼 건강 앱 선언 항목을 확인해야 합니다. 건강 기능이 없다고 판단해도 선언 양식 자체는 작성해야 합니다. 의료적 진단·치료 효과를 스토어 설명에 추가하지 않습니다.

4. **스토어 자료와 테스트**
   - 앱 이름·소개·문의 이메일, 512×512 아이콘, 1024×500 피처 그래픽, 실제 앱 화면을 준비합니다. 최종 스크린샷에는 테스트 알림이나 오류 화면이 없어야 합니다.
   - Android 16 실기기에서 권한 허용/거절, 호흡 취소, 회전, 뒤로 가기, 백그라운드 중단, 녹음 재생·삭제·내보내기를 확인하고 Play 사전 출시 보고서를 검토합니다.
   - 2023년 11월 13일 이후 생성된 신규 개인 계정이라면 최소 12명이 연속 14일 참여하는 비공개 테스트 후 프로덕션 액세스를 신청해야 합니다. 계정에 이미 적용/해제된 상태인지 콘솔에서 확인해야 합니다.

## 진행 순서

식별자·업로드 키 확정 → 개인정보처리방침·문의처 준비 → 서명된 AAB → 내부 테스트·사전 출시 보고서 → 스토어 자료·콘텐츠 선언 → 계정에 필요한 비공개 테스트 → 프로덕션 심사 제출.

현재 검토용 AAB 생성 성공은 빌드 가능성 확인입니다. Play Console 업로드·심사 통과·공개 배포를 의미하지 않습니다.
