# 상용 메트로놈 분석과 Local36 반영

확인일: 2026-10-31  
대상: Soundbrenner The Metronome, Pro Metronome(EUMLab), Tempo(Frozen Ape)의 공식 안내. 기기에서 세 앱을 설치해 비교한 결과는 아니며, 공식 제품 설명에서 기능과 조작 구성을 확인했습니다.

## 확인한 요소와 선택

| 제품 | 공식 안내에서 확인한 요소 | 보이스라인에 반영한 방향 |
|---|---|---|
| Soundbrenner The Metronome | 박별 강세 상태, 소리/시각 효과 설정, 곡·세트리스트 저장 | 강세 구분을 명확히 하고 이름 붙인 리듬 저장 제공 |
| Pro Metronome | 큰 재생 버튼, BPM 직접 입력, 설정 패널, 소리·음량, 시각 박과 가로 모드 | BPM·재생을 중심에 두고 상세 설정을 탭으로 분리 |
| Tempo for Android | 화면 크기를 고려한 구성, 여러 세트리스트에 프리셋 저장 | 가로 화면의 높이를 아끼고 저장한 설정을 페이지로 불러오기 |

공식 출처:

- [Soundbrenner 앱 매뉴얼](https://www.soundbrenner.com/pages/manual-the-metronome-app)
- [Pro Metronome 공식 지원](https://eumlab.com/support/)
- [Tempo for Android 공식 소개](https://www.frozenape.com/tempoandroid-metronome.html)

다음 화면 구성은 이 요소를 참고해 보이스라인에 맞게 선택한 설계입니다. 타사의 화면·이미지·아이콘·코드를 복사하지 않았습니다.

## Local35의 가독성 문제

1. 현재 박 숫자가 BPM보다 커서 빠르기를 찾을 때 시선이 분산됐습니다.
2. 박자표·BPM 기준·세분이 작은 폼으로 나란히 있어 읽을 항목이 많았습니다.
3. 작은 설명과 상태 문구가 반복되고 세분 숫자는 매우 빠르게 바뀌었습니다.
4. 소리와 사용자 지정 기능의 진입점이 하나로 모여 목적을 알아보기 어려웠습니다.

## Local36 화면의 우선순위

- **첫 번째:** 큰 BPM 숫자와 켜기/끄기.
- **두 번째:** 현재 박, 한 마디 박 수, 강세/보통/묵음.
- **세 번째:** 박자·세분·기준 음표를 여는 요약 버튼.
- **필요할 때:** 박자 / 소리 / 저장한 리듬의 설정 탭.

좌측은 빠르기와 재생, 우측은 현재 박과 리듬으로 구분했습니다. 숫자 크기·버튼·글자 대비를 정리하고, 세분마다 변하는 작은 문구는 제거했습니다. 본 화면에 입력 폼을 계속 늘리지 않았습니다.

## 추가한 실용 기능

| 기능 | 동작 |
|---|---|
| 실시간 BPM | 숫자·버튼·슬라이더로 변경해도 현재 마디를 유지 |
| 세 가지 소리 | 클릭·우드·벨. 생성된 오디오이며 추가 음원 다운로드 불필요 |
| 빠른 음소거 | 소리만 끄고 시각 박자와 마디 진행은 유지 |
| 음량 변경 | 예약된 박을 취소하지 않고 출력 음량만 조절 |
| 저장한 리듬 | 이름을 붙여 최대 24개 저장. BPM·박자·강세·세분·소리 등을 함께 보관 |
| 리듬 페이지 | 저장 항목은 두 개씩, 박 버튼은 화면 폭에 맞춰 최대 여덟 개씩 표시 |
| 밀도 보호 | 초당 50회 초과 클릭 조합은 적용하지 않고 조정 방법을 안내 |

박자표·기준 음표·세분·강세의 구조를 바꾸면 새 리듬 첫 박부터 재생합니다. BPM·소리·음량은 현재 마디를 유지합니다.

## 이번에 늘리지 않은 기능

- 사용자가 제거한 탭 템포는 다시 넣지 않았습니다.
- 외부 기기 연결, 클라우드, 구독, 자동 훈련, 복잡한 폴리리듬은 추가하지 않았습니다.
- 앱을 벗어나면 중지하는 현재 동작과 녹음/연습 기록 분리를 유지합니다.
- 기본 박자표와 1~64박의 사용자 지정 범위는 유지합니다.

## 검증 범위

총 129개 검사 통과, 실패·건너뜀 0. 재생 연속성, 소리·음량·음소거, 설정 저장/복원, 잘못된 자료, 저장 실패, 페이지, 전체 앱 연결을 가상 DOM과 오디오 시계로 검사했습니다.

실제 Android SDK APK 빌드와 WebView 화면 렌더링·마이크·스피커는 확인하지 못했습니다. 특히 Galaxy S24 Ultra / Android 16에서 기본/큰 글꼴과 키보드 열린 가로 화면의 잘림·스크롤을 확인해야 합니다. 매우 짧은 창에서는 접근을 보장하기 위한 스크롤을 허용합니다.

Local35 추가 점검의 다른 보완 제안은 같은 폴더의 `VoiceLine_Local35_Additional_Review_KO.md`에 있습니다. 이번 버전은 메트로놈의 가독성과 조작 개선에 집중했습니다.
