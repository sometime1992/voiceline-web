[이번 버전 및 유지 기능]
- 가로·세로 모두 지원합니다. 휴대폰 자동 회전 설정을 따르며 세로 전용 회전 안내창은 제거했습니다.
- 세로에서는 1옥타브, 가로에서는 2옥타브를 표시하고 기존 −/+로 전체 건반 음역을 이동합니다.
- 세로의 연습 설정은 두 열, 음역 슬라이드는 전폭 그래프와 하단 점수, 메트로놈은 BPM 아래 설정으로 배치합니다.
- 녹음·비브라토·기타 훈련의 세로 그래프는 건반 위에 별도로 배치하고 수치는 두 열로 표시합니다.
- 회전은 화면만 갱신합니다. 녹음 파일·훈련 진행 시간·예약된 가이드 음·메트로놈 박자·재생 위치를 유지합니다.
- 회전 중 누르고 있던 건반과 BPM 반복 입력은 해제해 화면 이동 뒤 입력이 계속되지 않게 합니다.
- 세로의 주 화면은 별도 페이지 스크롤 없이 구성합니다. 기록·긴 설명과 키보드 등으로 남은 높이가
  480px 이하인 작은 화면에서는 잘림을 피하기 위해 필요한 스크롤을 허용합니다.
- 음역 슬라이드의 목표음·내 음·그래프 눈금·첫 음·기준음·설정·결과에 C4 · 2옥 도처럼 표시합니다.
  기존 범례와 표시 칸을 사용하며 주 화면의 행이나 높이는 늘리지 않습니다.
- 작은 가로 화면에서 음정 표시 카드 폭이 다시 23%로 줄어들던 스타일을 수정했습니다.
  그래프는 계이름 폭을 안쪽 여백에서 확보하고 범례는 한 줄로 유지합니다.
- 건반 위 음역과 모든 시작음 선택 목록의 옥타브 그룹도 한국식 발성 옥타브로 맞췄습니다.
- 일반 훈련·음정 연습에서 직전 무음을 발성 시간으로 채우지 않으며 청음의 듣기 시간도 제외합니다.
  성공 기준 65% 미만을 반올림으로 통과시키지 않고 표시·결과·기록의 퍼센트를 맞췄습니다.
- 녹음 종료 중 즉시 발생한 오류로 저장 대기 상태가 계속 남는 문제를 수정했습니다.
- 예전 녹음의 미디어 길이가 Infinity/NaN이어도 저장된 길이로 재생 위치를 옮길 수 있습니다.
  재생 실패 시 소스를 해제하며 이전 재개 요청의 늦은 실패는 새 재생을 방해하지 않습니다.
- WAV 복구는 완료 표시만 신뢰하지 않고 실제 PCM 길이와 RIFF/data 길이를 대조합니다.
  형식이 정상인 파일의 길이 불일치를 복구하고 남아 있는 온전한 표본을 보존합니다.
- 사용법의 건반 소리 진단·마이크 연결 상태 확인과 리듬·음절 훈련을 제거했습니다.
- 전용 순음·진단 인터페이스, 미사용 상태값·스타일과 음절 훈련 전용 코드를 정리했습니다.
- 손상된 음정 자료로 그래프가 멈추는 경로와 점수 반올림의 경계값 판정을 보완했습니다.
- 가이드 따라 부르기를 음역 슬라이드로 이름을 바꾸고 기존 슬라이드 기능을 모두 통합했습니다.
  별도의 예전 슬라이드 메뉴를 없애고 한 패턴 목록에서 18종을 선택합니다.
- 메트로놈 −/+ 길게 누르기로 BPM을 연속 조절하고 텍스트의 길게 누르기 메뉴를 막았습니다.
- 가이드 종료 후 3초간 3·2·1을 표시하고, 시작!과 첫 음 시작선을 안내합니다.
- 마이크 켜짐·꺼짐 안내는 앱 이름과 마이크 버튼 사이의 상단 여백에 표시합니다.
- 통합 슬라이드 메뉴 아이콘을 다른 메뉴와 같은 폭 안에 맞췄습니다.
- 한 구절 듣기 → 3·2·1 준비 → 따라 부르기 → 음정·발성 시간 확인을 지원합니다.
  3가지 가이드 소리와 회차별 반음 이동을 선택할 수 있습니다.
- 녹음 복구 정보가 손상되거나 없어도 정상 WAV 헤더로 다시 구성합니다.
  복구할 수 없는 항목은 오류를 표시하고 원본 파일 저장·삭제를 제공합니다.
- 나의 기록 > 녹음 > ⋯에서 이름 변경, 파일로 저장, 공유, 삭제를 제공합니다.
- 녹음 이름·날짜 검색과 MB/GB 용량 표기를 추가했습니다.
- 1초 미만 녹음의 그래프·재생선·이동 막대에 실제 길이를 적용합니다.
- 긴 재생 곡선을 캐시하고 화면 폭에 맞게 줄입니다. 무음과 음역 변화는 보존합니다.
- 네이티브 분석 대기는 JavaScript 실행 완료까지 최대 3개입니다.
  분석이 늦어져도 WAV 오디오 표본은 별도로 계속 저장합니다.
- 녹음 화면에 남은 공간과 WAV 기준의 예상 녹음 시간을 표시합니다.
- 호흡·워밍업에 단계별 시간과 안내음 설정을 추가했습니다.
- 예비 피아노도 포함된 Salamander MP3를 사용하며 오래된 OGG 경로를 제거했습니다.
- 그래프·파일 전달 코드와 새 설정 스타일을 별도 파일로 분리했습니다.
  이전 워밍업 그래프 분기, 쓰지 않는 상태값·보정표를 정리했습니다.

[사용법과 메뉴 정리]
1. 사용법은 현재 제공하는 11개 모드의 설명과 음역·기록·음원·마이크 사용 안내를 제공합니다.
   건반 소리 진단·마이크 연결 상태 확인 테스트는 제거했습니다.
2. 리듬·음절 훈련은 메뉴·전용 실행·설명에서 제거했습니다. 박자 조절은 메트로놈을 이용하세요.
   이전에 저장한 리듬 훈련 기록과 녹음은 삭제하지 않습니다.
3. 비브라토의 측정 기준·입력 오류 알림·마이크 권한 요청과 실제 음정 분석은 유지합니다.

[가로·세로 사용]
1. 휴대폰의 빠른 설정에서 자동 회전을 켜면 방향을 따라 배치가 바뀝니다.
   화면 회전 잠금이 켜져 있으면 휴대폰에서 선택한 방향을 따릅니다.
2. 별도 앱 설치나 데이터 이전은 필요하지 않습니다. 같은 앱에서 모든 11개 모드를 사용합니다.
3. 세로는 넓은 건반 1옥타브이며, 가로는 기존 2옥타브입니다. C1~B7 연주 범위와
   목소리 감지 범위 C2~A♯6을 유지합니다. 목표·감지 음이 표시 밖으로 나가면 건반이 따라갑니다.
4. 세로의 연습 설정은 두 열로 모두 표시하며 좌우 스크롤 화살표는 나타나지 않습니다.
   긴 설명은 기능 이름 옆 설명 버튼, 슬라이드 세부 설정은 연습 설정 버튼을 사용하세요.
5. 세로 메트로놈은 BPM·재생을 위에, 박자·세분·소리·음량·강세 설정을 아래에 둡니다.
   박별 강세와 저장 리듬은 기존 창에서 같은 방식으로 사용합니다.
6. 회전만으로 녹음을 저장·분할하거나 연습·메트로놈을 중단하지 않습니다.
   손으로 누르던 건반과 BPM 길게 누르기는 해제합니다. 실제 앱 이탈·입력 오류에서는 기존처럼 종료합니다.
7. 기본 훈련 주 화면은 한 화면에 맞추며, 기록·긴 설명·작은 창·화면 키보드에서는 필요한 스크롤을 허용합니다.
   실제 기기의 화면 배율·글꼴·내비게이션 방식에 따른 잘림/스크롤 여부는 기기에서 확인하세요.

[상단 마이크 안내]
1. 켜짐·꺼짐 안내는 앱 이름 오른쪽의 빈 공간에 표시하고 연습 화면을 덮지 않습니다.
2. 안내는 약 4.1초 뒤 사라지며 ×로 닫을 수도 있습니다. 닫기는 마이크를 끄지 않습니다.
3. 좁은 화면에서는 안내를 짧게 표시하고 중복된 현재 기능 칩을 숨겨 버튼 공간을 확보합니다.
   상단 높이는 유지하며 안내 때문에 주 화면의 세로 스크롤이 생기지 않도록 구성했습니다.

[음역 슬라이드 - 통합 메뉴]
1. 메뉴 > 음역 슬라이드를 선택합니다. 가이드 따라 부르기와 예전 슬라이드를 하나로 통합했습니다.
   별도의 예전 음역 슬라이드 메뉴나 단계별/연속 전용 화면은 없습니다.
2. 패턴 선택은 세 그룹으로 구분합니다.
   - 음계·도약 10종: 5음 왕복, 3화음, 단조, 5음 하행, 아르페지오, 옥타브,
     반음 왕복, 3도 연결, 한 옥타브 음계 왕복, 기준음 복귀.
   - 단계별 왕복 4종: 반음씩 3·5·7·12반음 범위를 올라갔다 내려옵니다.
   - 연속 슬라이드 4종: 같은 범위에서 6초 이동 후 6초 돌아오며 음을 부드럽게 연결합니다.
3. 일반·단계별 패턴은 50~120 BPM(한 음 1박) 또는 한 음 2·3·4초 유지를 고릅니다.
   고정된 초를 선택하면 BPM 입력은 비활성화합니다. 연속은 한 구절 12초로 고정합니다.
4. 시작음, 1~5회 반복과 같은 음역/회차마다 반음씩 상승·하강을 설정합니다.
   감지 범위 C2~A♯6을 유지합니다. 기존 단계별·연속 패턴의 높은 시작음은 아래로 왕복합니다.
   다음 회차가 범위를 벗어나면 거기서 끝냅니다. 실제 음역과 총 시간을 미리 표시합니다.
5. 피아노·허밍 톤·모음 톤과 전용 음량을 선택합니다. 일반 패턴 피아노는 포함 MP3를 사용합니다.
   연속 패턴은 음높이가 끊기지 않도록 선택한 소리의 합성 지속음을 사용합니다.
   허밍·모음은 합성 안내음이며 가수 음성이나 첨부 영상은 앱에 포함하지 않습니다.
6. 1.8초 준비 → 한 구절 듣기 → 3·2·1 준비 → 시작!에 첫 음부터 따라 부르기 순서입니다.
   준비는 3초이며 숫자·첫 음·시작선을 표시합니다. 답변에는 가이드 음이 나오지 않습니다.
   이후 1.4초 쉬고 다음 회차로 갑니다. 긴 단계별 패턴은 짧은 범위부터 시작하세요.
7. 민트색 목표선과 보라색 목소리를 같은 축에서 비교합니다.
   목표음·내 음·눈금·첫 음과 기준음에 C4 · 2옥 도처럼 영문 음명·옥타브·계이름을 표시합니다.
   C4 = 2옥 도라는 기존 기준을 그대로 사용합니다. 범례는 기존 한 줄 안에서 갱신합니다.
   단계별은 계단, 연속은 기울어진 선입니다. +cent는 목표보다 높고 −cent는 낮다는 뜻입니다.
8. 듣기·준비·쉬기는 채점하지 않습니다. 일반 패턴은 음마다 처음 0.1초를 제외합니다.
   연속은 응답 처음 0.1초만 제외하고 전체 이동을 평가합니다.
   일반은 ±35·50·75cent를 고르고, 연속은 ±110cent입니다.
   성공은 일치율 65% 이상, 전체 발성 40% 이상, 측정 12개 이상이 필요합니다.
   일반은 각 음 20% 이상, 연속은 올리기·내리기 각 절반의 4구간마다 20% 이상 발성이 필요합니다.
   정수 퍼센트 표시는 기준 미달을 반올림으로 통과시키지 않도록 내림하며 소수점 오차를 보정합니다.
   일치율은 발성한 시간 중 허용 범위에 든 비율입니다. 커버리지는 전체 응답 시간 중 발성 비율입니다.
9. 결과와 더 연습할 음/이동 구간은 연습 기록에만 저장하며 음성 파일은 만들지 않습니다.
   예전 두 기능의 기록은 원래 이름과 내용 그대로 보존합니다.
10. 기존 가이드 설정이 있으면 우선 유지합니다. 없으면 예전 슬라이드의 방식·범위·시작음·
    한 음 유지 시간을 통합 설정으로 옮깁니다. 이전 설정 원본은 삭제하지 않습니다.
11. 중단·모드 이동·앱 이탈·오디오 중단에서 예약음과 마이크를 종료합니다.
    주 화면은 패턴·연습 설정만 유지하고 자세한 설정은 별도 창에 둡니다.
12. 이어폰을 사용하고 편안한 음역에서 시작하세요. 실제 마이크 지연·주변 소리에 따라 차이가 있습니다.

[길게 누르기]
1. 메트로놈 −/+는 한 번 누르면 1 BPM, 길게 누르면 0.4초 뒤부터 0.08초마다 1 BPM을 조절합니다.
   손을 떼기·버튼 밖으로 이동·터치 취소·창 이탈·다른 모드 이동에서 반복이 멈춥니다.
   20~300 BPM 범위와 과도한 세분 조합 차단을 유지하며 재생 중에는 현재 마디를 이어갑니다.
2. 앱 글자·이미지의 복사·번역·모두 선택 팝업은 표시하지 않습니다.
   입력창은 키보드로 이름·검색어·숫자를 편집할 수 있으며 앱의 파일 저장·공유 버튼은 유지합니다.
   피아노 건반을 길게 누르는 연주, 슬라이더와 버튼의 실제 터치 동작은 차단하지 않습니다.

[녹음 파일 보관·관리]
1. 메뉴 > 녹음하기 > 녹음 시작을 누릅니다. 중지·저장까지 한 파일로 이어집니다.
   무음도 포함하며 임의의 10분 제한과 자동 파일 분할은 없습니다.
   앱 이탈, 실제 입력·저장 오류에서는 그 시점까지 종료·저장합니다.
2. 메뉴 > 나의 기록 > 녹음에서 이름·날짜를 검색할 수 있습니다.
   목록은 작은 메타데이터만 읽고 더 불러오기로 이어집니다.
3. 전체 재생은 같은 버튼으로 일시정지·재개합니다. 막대로 재생 위치를 옮깁니다.
4. 녹음 옆 ⋯을 누르면 관리 창이 열립니다.
   - 이름 변경: 이름 입력 후 이름 변경을 누릅니다. 음성과 날짜·음정 자료는 유지됩니다.
   - 파일로 저장: Android 시스템 창에서 폴더와 파일 이름을 선택합니다.
     복사가 끝나야 저장 완료를 표시합니다. 취소·실패 시 앱 원본은 유지됩니다.
   - 공유: 카카오톡 등 사용할 앱을 사용자가 고릅니다.
     공유 창을 열었다는 안내이며 상대에게 실제 전송이 끝났다는 뜻은 아닙니다.
   - 녹음 삭제: 확인창을 거쳐 앱 안의 원본을 삭제합니다.
5. 현재 Android 녹음은 WAV입니다. 예전 WebM/M4A/Blob 녹음은 원래 형식으로 내보냅니다.
   현재 WAV는 파일을 직접 스트림 복사합니다. 예전 Blob은 64KB씩 임시 파일을 준비하므로
   기기에 원본 크기만큼 추가 공간이 필요할 수 있습니다.
   공유용 예전 형식 임시 파일은 다음 시작 때 24시간이 지난 파일을 정리합니다.
6. 다른 녹음을 녹음 중이라면 먼저 중지·저장한 뒤 파일 저장·공유를 이용하세요.
7. 저장하지 못한 녹음 목록에서는 다시 저장을 시도할 수 있습니다.
   보조 정보를 읽을 수 없어도 WAV가 정상이면 정보 재구성을 시도합니다.
   헤더·파일 접근 문제가 있으면 오류를 표시하고 원본 파일을 외부로 저장할 수 있습니다.
   실제로 없는 음성이나 손상된 음성을 모두 복원할 수 있다는 보장은 아닙니다.
8. 앱의 원본 WAV 위치(기본 사용자 프로필의 Debug 설치 기준):
   /data/user/0/com.voiceline.app.local18/files/voiceline-recordings/
   내부 보관 영역이므로 일반 파일 관리자에서는 직접 열 수 없습니다.
   파일로 저장에서 고른 외부 복사본은 선택한 위치에 따로 남습니다.
9. 파일 내보내기는 음성의 별도 보관 기능입니다. 전체 연습 기록·설정을 새 기기로
   복원하는 백업/가져오기 기능과는 범위가 다릅니다.
10. 녹음 화면의 여유 공간·예상 시간은 현재 입력 속도와 WAV 크기 한계를 기준으로 한
    대략적인 값입니다. 다른 앱의 공간 사용에 따라 바뀌며 약 64MB를 여유로 남깁니다.

[메트로놈]
1. 메뉴 > 메트로놈을 고릅니다. 마이크와 녹음은 필요하지 않습니다.
2. BPM 영역에 현재 박·마디와 BPM을 표시합니다. 숫자·+/−·슬라이더로 20~300 BPM을 조절합니다.
   +/−는 길게 눌러 연속 조절할 수 있습니다.
3. 메트로놈 켜기/끄기와 소리 켜짐/꺼짐 버튼을 사용합니다. 탭 템포는 없습니다.
4. 박자 설정 영역에서 박자표, BPM 기준, 세분, 직접 박자표, 클릭 소리와 음량을 바로 조절합니다.
   가로에서는 오른쪽, 세로에서는 BPM 아래에 표시됩니다.
   - 기본 박자표 19개, 직접 설정 1~64박, 분모 1·2·4·8·16·32·64
   - 세분 1·2·3·4·6·8, BPM 기준 1박/4분음표/점4분음표
   - 클릭/우드/벨 소리
5. 강세 묶음에 2+2+3처럼 한 마디 박 수와 같은 합계를 입력하고 적용을 누릅니다.
   기본 강세로는 본 화면과 박별 강세 창 양쪽에 있습니다.
   현재 박자표의 기본 강세를 복원하며 BPM·음량은 유지합니다.
6. 박별 강세에서 각 박을 강세 → 보통 → 묵음으로 바꿉니다. 많은 박은 페이지로 표시합니다.
7. 저장 리듬에서 이름을 붙여 최대 24개 저장·불러오기·삭제합니다.
8. BPM·소리·음량·음소거 변경은 현재 마디를 유지합니다.
   박자·BPM 기준·세분·강세 변경은 첫 박부터 시작합니다.
9. 초당 50회가 넘는 클릭 조합은 적용하지 않고 안내합니다.
10. 설명 버튼은 기능 이름 바로 옆에 있습니다. 일반 가로 화면의 조작 행 수는 유지합니다.
    키보드·큰 글꼴·아주 짧은 화면에서는 잘림을 피하기 위한 스크롤이 필요할 수 있습니다.

[호흡·워밍업]
1. 기본은 들이쉬기 4초 → 내쉬기 6초 → 허밍 6초 → 쉬기 3초입니다.
2. 시간·안내음에서 들이쉬기·내쉬기·허밍을 각각 1~30초, 쉬기를 0~30초로 정합니다.
   쉬기 0초는 생략합니다. 기본값 버튼은 워밍업 설정만 복원합니다.
3. 내쉬기를 마치면 초록색 지금 허밍하세요 안내에 맞춰 입을 가볍게 다물고 음~ 하세요.
   안내음이 켜져 있으면 허밍 시작은 높은 딩딩 두 번, 쉬기는 낮은 안내음입니다.
4. 안내음을 끄면 화면으로 진행합니다. 화면과 소리는 같은 단계별 시간표를 사용합니다.
5. 단계·남은 초·다음 단계가 표시됩니다. 진행 횟수는 1~3세트입니다.
6. 중단·모드 이동·앱 이탈에서 예약 안내음을 취소합니다.
   안내형 타이머로 실제 호흡량이나 허밍 수행 자체는 판정하지 않습니다.

[기존 데이터와 업데이트]
- 녹음과 연습 기록은 별도 탭이며 녹음 중 연습 이력을 만들지 않습니다.
- 기존 Blob 녹음, Local32/33 임시 PCM 복구와 현재 Native WAV를 유지합니다.
- IndexedDB 이름 voiceline-local-v2, 스키마 4, Debug 앱 ID com.voiceline.app.local18을 유지합니다.
- 기존 앱을 삭제하지 말고 같은 PC·디버그 서명으로 업데이트하세요.
- 앱 삭제·데이터 초기화 시 앱 안의 녹음·연습 기록·설정은 삭제됩니다.
  필요한 음성은 미리 파일로 저장하여 별도로 보관하세요.
- 피아노 MP3 28개와 아이콘·라이선스 자료는 이전과 같습니다.

[Android Studio 빌드 - Windows]
1. 압축을 C:\Projects 같은 짧은 경로에 풉니다.
2. setup-gradle.bat를 최초 한 번 실행합니다. Gradle 준비에는 인터넷이 필요합니다.
   ZIP에 gradle-wrapper.jar는 포함하지 않습니다. 스크립트가 공식 파일을 받습니다.
   수동 다운로드: https://raw.githubusercontent.com/gradle/gradle/v8.10.2/gradle/wrapper/gradle-wrapper.jar
   저장 위치: gradle\wrapper\gradle-wrapper.jar
3. Android Studio > File > Open에서 VoiceLine_AndroidStudio 폴더를 선택합니다.
4. Gradle Sync와 SDK 설치를 진행합니다.
   JDK 17 / SDK 35 / AGP 8.8.2 / Gradle 8.10.2 기준입니다.
   androidx.webkit 1.12.1과 파일 공유용 androidx.core 1.15.0을 사용합니다.
   첫 Sync에서는 Maven 의존성을 받기 위한 인터넷 연결이 필요합니다.
5. USB 디버깅을 켠 기기를 연결하고 Run > Run 'app'으로 실행합니다.
6. 메뉴 하단 버전 2.0.0-local44를 확인합니다.
