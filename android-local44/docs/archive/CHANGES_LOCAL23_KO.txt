VoiceLine Local23 — 비브라토 진단 표시 및 로고 확인

1) 실제 마이크 PCM 묶음: 기존 4096샘플(44.1kHz에서 93ms)에서 2048샘플(약 46ms)로 축소. 16kHz 폴백에서는 1024샘플(64ms).
2) 비브라토는 매 35ms 분석을 시도하지만 데이터가 도착하는 간격의 한계를 받습니다.
3) 분석 기준은 최근 3초, 기준음 ±1.5반음, 유효점 16개 이상/0.9초 이상, 진폭 ±7~125cent, 반복 속도 3~9Hz, 신뢰 가능한 주기 4개.
4) 화면에 기준음 이탈/진폭 부족/주기 수/불규칙 등의 원인을 직접 표시하고 4주기 진행 표시.
5) 선택한 네온 글래스 로고를 앱 상단에도 추가. 런처 매니페스트 아이콘 및 5개 밀도 리소스 포함 여부 검증.
6) Android Studio 직접 Run / Build APK. GitHub Actions 사용 안 함. 기존 local18 APK와 같은 패키지 ID 및 서명일 때 데이터 보존.

홈 화면 로고가 예전 그림이라면: 새 ZIP의 VoiceLine_AndroidStudio 폴더를 열고 Build > Clean Project, Build APK(s) 후 새 APK 설치. 기존 APK가 남아 있으면 먼저 기존 설치 앱의 이름과 패키지 확인. 기존 녹음 보호를 위해 앱 데이터 삭제나 무작정 제거하지 말 것. 삼성 One UI에서 테마 아이콘이 켜져 있으면 단색 버전으로 보일 수 있음.

7) 비브라토 연습의 상단 설정 영역에 「ⓘ 측정 기준」 버튼 추가. 현재 알고리즘의 실시간 분석 간격, 최근 3초 관측창, 기준음 ±150cent, 최소 자료 16개/0.9초, 진폭 ±7~125cent, 속도 3~9Hz, 믿을 수 있는 주기 4개와 일치 허용폭 ±35%를 독립된 팝업으로 표시.
8) 목소리 입력이 0.6초 이상 감지되지 않으면 일시적으로 멈춘 이유를 화면에 안내.
