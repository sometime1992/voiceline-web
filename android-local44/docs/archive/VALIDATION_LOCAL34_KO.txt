Local34 배포 전 확인
===================
코드·회귀 검사: 107개 통과, 실패 0, 건너뜀 0.
검사 환경: Node.js와 JDK 17. Android API 스텁 및 실제 Java 파일 입출력 포함.
Android SDK APK 빌드 및 실제 마이크·WebView·스피커 검사는 수행하지 않았습니다.

정적 검사
- JavaScript 4개 파일 문법 검사 통과.
- HTML 중복 ID 없음, 로컬 스크립트/스타일/아이콘 참조 확인.
- XML/JSON/PNG 검사 통과.
- MP3 28개와 PNG/SVG 아이콘은 Local33의 원본 바이트를 유지.
- Debug 앱 ID com.voiceline.app.local18 유지, 버전 2.0.0-local34 / code 49.
- 기기별 설정 파일, 빌드 산출물, 서명 키는 포함하지 않음.
- ZIP 내 모든 파일은 작업 원본과 바이트 단위 비교. 손상/중복 경로 없음.

중요 검증 범위
- 네이티브 마지막 입력 이후 완료 응답, 시작/무음/끝 표본 보존.
- 저장 파일 헤더 복구, 음정 증분 보관, 바이트 구간 재생, 안전한 파일 ID.
- 복구 저장 중 뒤로가기 보호, 오디오 표본 기반 그래프 시간.
- 비브라토의 연속 주기·최근값·유효 시간, 피아노 실패/시간 초과/재시도.
- 기록 본문/메타데이터 원자적 저장, 작은 목록 저장소 사용.
- 전체 앱과 메트로놈 연결, 448개 사용자 지정 박자 조합, BPM 기준·강세·묵음·세분.
- 오디오 시계 일정 간격, 화면 지연 후 몰아서 클릭하지 않음, 중지/오디오 중단 처리.
