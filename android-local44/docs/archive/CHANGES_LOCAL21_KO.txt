VoiceLine Local 21 · 음정 연습 패턴과 자동 반복
1. 음정 연습 패턴 13종(기존 4 + 신규 9).
2. 반복 1,2,3,5회 또는 계속 반복. 기본 2회.
3. 3초 시작 카운트, 회차 사이 1.4초 준비, 목표음 자동 재생, 누적 진행률 및 회차 표시.
4. 반복 완료 시 자동으로 마이크 종료·기록 저장. 계속 반복은 사용자가 중단하면 완료된 회차가 기록됩니다.
5. 마지막 음이 끝난 뒤 또는 준비 시간에는 음정 정확도 측정 중단. 저장된 설정은 다음 실행에 복원.
6. 스마트폰 가로 UI에서 옵션 가로 스크롤. 기능은 기존 Local20 기반 유지.
APK는 사용자가 Android Studio에서 빌드. GitHub Actions 사용하지 않음.
