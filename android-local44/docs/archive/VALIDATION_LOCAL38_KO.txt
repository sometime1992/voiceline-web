Local38 배포 전 확인
===================
버전: 2.0.0-local38 / versionCode 53
코드·회귀 검사: 129개 통과 / 실패 0 / 건너뜀 0.

확인
- 기능 이름 옆 설명 버튼의 기존 배치를 유지하고 메트로놈의 양쪽 끝 정렬을 수정.
- 본 화면의 복원 버튼과 박별 강세 창 안의 기존 복원 버튼 모두 동작.
- 4/4·6/8·7/8·1/64에서 기본 강세 복원, 묶음 입력 초기화, BPM/박자표/세분/소리/음량 보존.
- 메트로놈 전체 동작, 녹음/복구/표본 보존/구간 재생, 비브라토/음원/워밍업 회귀 검사.
- HTML ID 중복·접근성 참조·실제 복원 버튼 배치, JavaScript 4개 파일 문법.
- CSS 괄호/블록 구조, 정적 파일 참조, XML/JSON/PNG 검사, 음원 28개 포함.
- 네이티브 Java·XML·아이콘·MP3 바이트는 Local37과 동일.
- ZIP의 모든 파일과 작업 원본 일치, 손상·중복 경로 검사.

한계
Android SDK APK 빌드, 실제 WebView 화면 렌더링 및 휴대폰 오디오는 미확인입니다.
