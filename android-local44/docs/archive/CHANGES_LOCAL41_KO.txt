보이스라인 Local41 - 음역 슬라이드 통합과 길게 누르기 개선
날짜: 2026-10-31
버전: 2.0.0-local41 / versionCode 56

1. 가이드 따라 부르기의 표시 이름을 음역 슬라이드로 변경했습니다.
   예전 음역 슬라이드 메뉴와 독립 실행·제어·판정 코드를 제거했습니다.
   메뉴의 슬라이드는 하나이며 총 모드는 피아노를 포함해 12개입니다.
2. 통합 패턴은 음계·도약 10종 + 단계별 왕복 4종 + 연속 슬라이드 4종의 18종입니다.
   단계별과 연속은 기존 3·5·7·12반음 범위를 지원하고 높은 시작음에서 아래로 왕복합니다.
   한 음은 BPM 또는 2·3·4초 유지로 설정합니다. 연속 패턴은 한 구절 12초입니다.
3. 모든 패턴을 한 구절 듣기 → 3·2·1 준비 → 혼자 따라 부르기 흐름으로 실행합니다.
   연속 패턴에는 기울어진 목표선과 부드러운 합성 지속음 가이드를 제공합니다.
   그래프·소리·현재 목표와 채점이 동일한 시간표를 사용합니다.
4. 일반은 ±35·50·75cent, 연속은 ±110cent로 비교합니다.
   충분한 전체 발성 및 각 음/이동 구간 발성이 없으면 성공으로 표시하지 않습니다.
   연속 구간은 처음 0.1초만 제외하고 이후 음정을 계속 비교합니다.
5. 기존 가이드 설정을 우선 유지합니다. 없으면 예전 슬라이드의 범위·방식·시작음·
   한 음 유지 시간을 가져옵니다. 기존 녹음과 두 연습의 과거 기록·설정 원본은 보존합니다.
   과거 모드 ID로의 요청은 통합 모드로 연결합니다.
6. 메트로놈 −/+ 길게 누르기를 추가했습니다.
   첫 터치 1 BPM → 0.4초 뒤 반복 → 0.08초마다 1 BPM으로 조절합니다.
   손 떼기·터치 취소·영역 이탈·포커스 상실·앱 이탈·모드 이동에서 반복을 취소합니다.
   한 번 누르기의 중복 변경을 막고 20~300 경계와 현재 마디 유지 동작을 보존했습니다.
7. 앱의 길게 누르기 복사·번역·전체 선택 메뉴를 차단했습니다.
   일반 글자의 선택·웹 문맥 메뉴와 Android 텍스트 작업 표시줄을 차단합니다.
   입력창의 키보드 편집, 건반 누르기, 슬라이더·버튼 동작과 파일 저장·공유는 유지합니다.
   터치 자체를 모두 가로채는 방식은 사용하지 않습니다.
8. Local40의 상단 마이크 안내·SVG 아이콘·3초 준비·가로 화면 구성은 유지합니다.
   사용 안내와 설정 설명을 통합 기능에 맞추고 이전 변경 문서는 docs/archive로 옮겼습니다.

검사: 전체 197개 통과 / 실패 0 / 건너뜀 0.
단계별 음 순서·유지 시간·높은 시작음, 연속 목표·오디오 램프·지연·채점·그래프,
설정 이전과 기존 기록 보존, 길게 누르기 반복·취소·경계·재생 유지,
웹 문맥 메뉴·입력창 선택과 Native 작업 표시줄 차단을 확인했습니다.
Java 검사는 Android API 대체 객체와 실제 소스를 함께 컴파일·실행한 범위입니다.
APK 빌드, 실제 WebView 렌더링과 휴대폰 오디오·터치 검사는 미진행입니다.
