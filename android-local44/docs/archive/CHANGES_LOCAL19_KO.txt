보이스라인 Local 19 / 녹음 음높이 그래프 끊김 완화

보고된 증상: 녹음 소리는 계속 들어오지만 음높이 그래프가 점선처럼 끊기거나 사라지는 경우.

변경사항:
1) 녹음 모드 마이크 감지 RMS 기준 완화: 0.009 -> 0.0028.
2) 입력을 22,050Hz로 다운샘플링해 YIN 음정 감지 구간을 충분히 확보함.
3) 녹음 중 짧은 미검출(최대 360ms)은 흐린 점선으로 연결. 실제 음정 수치/저장 데이터에는 반영하지 않음.
4) 장시간 무음/불명확한 피치/큰 음정 점프는 거짓 선을 만들지 않고 비워 둠.
5) 오디오가 감지되었지만 음정이 없을 때 별도 메시지 표시.
6) 저장 녹음 재생 그래프에도 짧은 결측 연결 표시 적용.
7) 기존 녹음·비브라토·피아노 음량 기능 모두 유지.
8) Android Studio 프로젝트 / 로컬 테스트 12개 포함. GitHub Actions 사용 안 함.

설치: ZIP을 풀어 VoiceLine_AndroidStudio 폴더를 Android Studio에서 Open. 최초 Gradle 설정은 setup-gradle.bat 이용.
테스트: 녹음하기 > 마이크 권한 허용 > 작은 목소리로 길게 노래 > 자음 발음 구간과 무음 구간 확인.
앱 ID com.voiceline.app.local18 유지 (같은 디버그 서명이면 기존 local18에 업데이트 가능).
