보이스라인 Local37 - 메트로놈 중복 숫자 제거·설정 바로 조절
날짜: 2026-10-31
버전: 2.0.0-local37 / versionCode 52

반영 내용
1. 오른쪽의 현재 박 표시와 숫자 박 버튼 줄을 기본 화면에서 제거했습니다.
   현재 박·마디와 박자표 요약은 왼쪽에 표시합니다. BPM 입력과 켜기/끄기도 왼쪽입니다.
2. 오른쪽 빈 영역에 박자표, BPM 기준, 세분 박자, 직접 박자표, 클릭 소리, 음량을 배치했습니다.
   별도 박자·음량 설정 버튼을 누르지 않고 본 화면에서 바로 조절합니다.
3. 강세 묶음 입력과 적용 버튼도 본 화면으로 옮겼습니다.
   개별 박의 강세/보통/묵음 편집은 '박별 강세' 안에 보관했습니다.
4. '직접 설정' 선택은 본 화면의 박 수 입력으로 이동하며 설정창을 열지 않습니다.
   1~64박, 분모 1·2·4·8·16·32·64, 세분 1·2·3·4·6·8을 유지합니다.
5. 설정창은 '박별 강세 / 저장한 리듬' 두 탭으로 정리했습니다.
   탭 키보드 이동, 닫은 뒤 초점 복원, 박 페이지와 이름 붙인 리듬 저장을 유지합니다.
6. 좌우 폭과 화면 높이에 따라 간격·글꼴·입력 높이를 조절합니다.
   키보드 등으로 화면 높이가 280px 이하가 되거나 큰 글꼴/긴 안내가 공간을 초과할 때는
   조작부가 잘리지 않도록 필요한 스크롤을 허용합니다.
7. 제거한 요약 버튼·소리 탭의 이벤트와 CSS, 사용하지 않는 표시 갱신 코드를 정리했습니다.
   앱 내 설명과 README도 새 조작에 맞게 수정했습니다.
8. BPM·음량·음소거·소리 변경은 재생 중 현재 박을 유지합니다.
   박자·BPM 기준·세분·강세 변경은 첫 박부터 시작합니다. 과도한 클릭 속도 보호를 유지합니다.
9. 네이티브 녹음 코드, 녹음/연습 이력 구분, 연속 녹음, 기존 저장 데이터,
   피아노 음원, 호흡·허밍 안내는 유지합니다. 탭 템포를 추가하지 않았습니다.
