보이스라인 Local33 - 녹음 연속 저장 및 기록 화면 분리
날짜: 2026-10-31
버전: 2.0.0-local33 / versionCode 48

수정 내용
1. 나의 기록 화면을 녹음 / 연습 탭으로 분리했습니다. 선택한 탭의 목록만 읽고 표시합니다.
2. 녹음 중 자동 음정 분석은 녹음의 그래프 자료로만 저장하며 연습 결과를 생성하지 않습니다.
   녹음 화면을 벗어나거나 저장이 끝난 직후에도 녹음 세션 정보를 기준으로 중복 기록을 막습니다.
3. 과거 버전의 녹음 완료·목소리 녹음·Recording 등의 이력이 연습 탭에 섞이지 않게 필터를 보완했습니다.
   기존 저장 데이터는 자동 삭제하지 않습니다.
4. 시작부터 중지까지 하나의 녹음 ID와 파일을 유지합니다. 조용한 구간도 그대로 포함합니다.
   반복 시작 호출은 진행 중인 녹음을 유지하고, 반복 중지 요청은 같은 저장 작업을 기다립니다.
5. 대기 중 임시 저장 개수만으로 녹음을 자동 중단하던 조건을 제거했습니다.
   10분 자동 종료도 제거하여 사용자가 중지할 때까지 이어집니다.
6. 브라우저 녹음은 시간별 출력 요청 없이 한 번 시작하고 중지 시 파일을 저장합니다.
   Android의 내부 복구용 임시 저장 단위는 하나의 WAV에 순서대로 결합됩니다.
7. Android의 일시적 onPause에서는 녹음을 끝내지 않고 실제 앱 이탈인 onStop에서 종료합니다.
   앱 전환·화면 잠금·실제 마이크/저장 오류는 해당 시점까지 한 파일로 보관합니다.
8. 전체 녹음 시간과 전체 재생 버튼을 표시했습니다. 실시간 음정 그래프의 최근 6초 구간은
   전체 녹음 길이와 별개이며, 음정 검출 실패가 오디오를 잘라 저장하지 않습니다.
9. 긴 녹음 그래프의 음역 계산에서 많은 인자를 펼치지 않도록 보완하고 WAV 크기 초과를 검증합니다.
10. 기존 Debug 앱 ID com.voiceline.app.local18, 저장소 이름, 녹음/연습 데이터를 유지합니다.

확인
- 원음의 시작·무음·끝 부분이 저장된 파일 1개에 바이트 단위로 그대로 이어지는지 검증했습니다.
- 저장 지연 중 세션 유지, 반복 시작/중지 시 단일 파일, 12분 경과 시 녹음 유지,
  녹음→연습 탭 전환, 과거 녹음 이력 필터, 녹음 중 연습 저장 차단을 검사했습니다.
- 코드 및 회귀 검사 80개 통과. 실제 Android APK 빌드와 휴대폰 녹음 테스트는 별도 필요합니다.

설치
- 기존 앱을 삭제하지 말고 같은 PC/디버그 서명으로 Android Studio에서 업데이트 설치하세요.
- 메뉴 하단 버전 2.0.0-local33으로 업데이트 적용 여부를 확인할 수 있습니다.
- 새 녹음부터 변경 사항이 적용됩니다. 이미 저장된 파일들은 원래 상태로 보존합니다.
