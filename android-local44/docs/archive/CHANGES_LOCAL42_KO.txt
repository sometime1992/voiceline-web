날짜: 2026-10-31
버전: 2.0.0-local42 / versionCode 57

제거·정리
1. 사용법에서 건반 소리 진단과 마이크 연결 상태 확인 테스트를 제거했습니다.
2. 진단 순음 재생/해제, 진단 토글, 전용 상태값과 JavaScript 진단 노출을 제거했습니다.
   사용처가 없어진 Native 마이크 진단 조회 메서드·공유 진단 문자열·Build import도 삭제했습니다.
   실제 입력의 권한·오류·연결 알림은 유지하고 각 이벤트의 직접 메시지로 처리합니다.
3. 리듬·음절 훈련을 제거했습니다.
   메뉴·설명·전용 클릭/카운트다운·음절 시작 감지·채점·그래프와 관련 상태/스타일을 삭제했습니다.
   현재 모드는 피아노를 포함해 11개입니다. 메트로놈과 예전 리듬 연습 기록은 유지합니다.
4. 쓰기만 하는 현재 음정/마지막 감지 시각, 미사용 통계, 불필요한 녹음 객체 보관,
   중복 음량 최고값, 비브라토 설명의 미사용 반환값과 존재하지 않는 CSS 선택자를 정리했습니다.
5. 이름 있는 앱 함수의 사용처와 Java import를 재확인했습니다.
   실제 피아노 예비 음원·녹음 복구·샘플·아이콘·음원 엔진과 라이선스는 유지합니다.

확인하여 수정한 문제
6. 손상된 녹음 음정 자료에 큰 유한 음정값이 있으면 음높이 눈금 반복이 과도해질 수 있었습니다.
   유효 MIDI 범위와 실제 녹음 시간 안의 점만 사용하고 잘못된 점은 선을 끊습니다.
   그래프 폭·길이를 검증하고 분할 배열 크기를 제한합니다.
   비정상 시간·파일 크기가 Infinity/NaN으로 표시되지 않도록 보완했습니다.
7. 슬라이드의 39.5% 커버리지나 64.5% 일치율이 반올림되어 기준을 통과할 수 있었습니다.
   기준 미달을 올리지 않는 정수 퍼센트와 작은 부동소수점 오차 보정을 적용했습니다.
8. BPM 반복 처리 중 취소되면 새 반복 타이머를 다시 만들지 않도록 확인을 추가했습니다.
