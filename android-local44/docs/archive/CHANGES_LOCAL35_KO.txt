보이스라인 Local35 - 메트로놈 가로 화면 개선 및 호흡·허밍 안내
날짜: 2026-10-31
버전: 2.0.0-local35 / versionCode 50

요청 반영
1. 템포 카드의 215/230px 최소 높이와 본 화면 스크롤 컨테이너를 제거했습니다.
   가로 화면의 남은 높이를 두 패널이 나누어 사용하도록 배치했습니다.
2. 상단 음표 정보·중복 상태·설정 안내·중복 시작/중지 버튼을 메트로놈 모드에서 정리했습니다.
   기능 제목과 설명 버튼은 유지하며 본문에서 쓸 수 있는 높이를 늘렸습니다.
3. BPM 숫자와 +/−를 한 줄에 두고 슬라이더와 켜기/끄기를 짧게 배치했습니다.
4. 리듬대로 누르기(탭 템포)를 제거하고 그 자리를 메트로놈 켜기/끄기 버튼으로 바꿨습니다.
   재생 여부에 따라 문구·색·접근성 상태가 바뀝니다. 빠르기 자체는 바뀌지 않습니다.
5. 본 화면에는 박자표·BPM 기준·세분·박별 강세를 남겼습니다.
   직접 지정 박 수/분모·강세 묶음·음량은 '박자·음량 설정' 창에 모았습니다.
6. 1~64박, 모든 기존 분모 및 강세·묵음·세분·복합박자 BPM 설정은 유지합니다.
   박 수가 많아도 줄이 계속 늘어나지 않도록 화면 폭에 맞춰 최대 8개씩 페이지로 표시합니다.
7. 박 페이지 이동은 재생이나 템포를 바꾸지 않습니다. 재생 중 현재 박을 자동 표시하며
   사용자가 페이지를 고르거나 편집할 때는 선택한 페이지를 유지합니다.
8. 설정창은 뒤로가기·Escape·닫기·배경 터치로 닫고 '박자·음량 설정' 버튼으로 초점을 돌립니다.
   창을 닫는 동작은 재생을 끄지 않습니다. 앱을 실제로 벗어나면 기존과 같이 중지합니다.
9. 슬라이더를 움직이는 동안 숫자가 함께 갱신되며 놓으면 적용합니다.
   BPM 숫자 입력 후 Enter/완료는 입력을 마치고 키보드를 닫습니다.

10. 호흡·워밍업에서 빈 음정 그래프 대신 현재 단계, 남은 초, 다음 단계와 4단계 순서를 표시합니다.
    들이쉬기 4초 → 내쉬기 6초 → 허밍 6초 → 쉬기 3초를 같은 시간표로 표시합니다.
11. 내쉬기 중에는 허밍이 시작될 때까지의 남은 시간을 표시합니다. 허밍 시작에는
    '지금 허밍하세요'를 초록색으로 강조하고 높은 안내음 두 번을 재생합니다.
    허밍 종료에는 '허밍을 멈추고 쉬세요'와 짧은 낮은 안내음을 제공합니다.
12. 안내음은 화면 프레임과 별개로 오디오 시계에 예약합니다. 중단·모드 이동·백그라운드에서
    취소하고, 오디오가 끊겼다 돌아와도 지난 단계의 소리를 몰아서 재생하지 않습니다.

검증 및 한계
- 총 119개 코드·동작·회귀 검사 통과, 실패 0, 건너뜀 0.
- 1~64박 페이지의 전체 접근, 마지막 박 편집과 설정 보관, 재생 중 페이지 이동·폭 변경,
  새 켜기/끄기 상태·예약 취소, 직접 설정 열기·수동 BPM 입력을 검사했습니다.
- 허밍 시작/종료 경계, 준비와 다중 세트, 두 번 안내음의 예약 시각, 중단·지연 승인·오디오 중단을 검사했습니다.
- 기존 녹음·복구·비브라토·음원·메트로놈 타이밍 검사도 함께 통과했습니다.
- XML/JSON/PNG, JavaScript 문법, 중복 HTML ID, 정적 참조, MP3/아이콘 원본 유지와 ZIP을 검사했습니다.
- 실제 브라우저/WebView 화면의 렌더링과 Android SDK APK 빌드는 수행하지 못했습니다.
  Galaxy S24 Ultra / Android 16에서 가로 화면 및 큰 글꼴의 잘림·스크롤 여부 확인이 필요합니다.
- 높이 260px 이하의 키보드 열린 화면 등에서는 접근성을 위해 필요한 스크롤을 허용합니다.
