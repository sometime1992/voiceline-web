VoiceLine Local27 - 녹음과 연습 기록 분리

- 녹음 저장 완료시 연습 기록(events)에 "녹음 완료" 행이 중복 생성되던 코드 제거.
- 녹음 파일은 recordings에 한 번만 저장하며 기존 음성·음높이 그래프·녹음시간은 그대로 유지.
- 이전 버전에 생성된 mode=record 또는 title=녹음 완료의 중복 이력은 연습 기록 화면에서만 숨김.
  원본 events 데이터나 녹음 파일은 삭제하지 않음 (데이터 보존).
- 연습 기록은 음정 연습, 비브라토 연습, 음정 측정 이력만 표시.
- 저장 후 삭제 즉시 갱신 및 기존 커스텀 삭제 확인창, 아이콘, 피아노 음량, 13종 연습 기능 유지.
- Local26과 같은 debug applicationIdSuffix .local18을 사용하고 versionCode=42로 업데이트.
  같은 서명으로 설치하면 기존 앱 데이터에 영향을 주지 않음.
- GitHub Actions 사용하지 않음. Android Studio에서 로컬 빌드.
