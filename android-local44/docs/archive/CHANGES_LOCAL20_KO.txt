VoiceLine Local20 — 나의 기록 삭제 직후 UI 갱신 수정

- 녹음 파일/연습 기록 삭제 버튼은 저장소 트랜잭션이 완료된 후 화면에서 항목을 제거합니다.
- 삭제 직후 목록의 녹음 파일(개수), 연습 기록(개수)이 실제 행 개수와 일치합니다.
- 마지막 항목을 삭제하면 안내 문구가 즉시 나타납니다.
- 기록 화면의 스크롤 위치를 유지하며 다른 녹음 재생은 중단하지 않습니다.
- 현재 재생 중인 녹음 파일을 삭제하는 경우에만 그 재생을 종료합니다.
- 연속 삭제 시 같은 삭제 요청이 중복 실행되지 않도록 버튼 비활성화, 실패 시 복구.
- Local19와 동일한 .local18 앱 ID를 사용하므로 동일 디버그 서명으로 설치하면 이전 기록을 유지합니다.
- GitHub Actions를 사용하지 않았으며 APK를 생성하지 않았습니다.
