VOICE LINE Local31 · 훈련별 설명 버튼

- 모든 훈련 및 피아노·음정 측정·녹음 화면의 제목 오른쪽에 「ⓘ 설명」 버튼을 추가했습니다.
- 버튼은 기존 보이스라인 정보창을 열어 현재 훈련의 목적, 방법 및 기준을 설명합니다.
- 상단 제목 아래의 긴 문단은 제거하고 간단한 상태만 표시합니다. 좁은 가로 화면에서는 이 상태 줄이 숨겨지며 설정 컨트롤은 유지됩니다.
- 기존 사용법, 비브라토 측정 기준, 훈련 결과창, 음원·녹음·기록 데이터는 유지했습니다.
- 이 프로젝트는 Android Studio에서 로컬로 빌드합니다. GitHub Actions 또는 별도 npm 설치가 필요하지 않습니다.
