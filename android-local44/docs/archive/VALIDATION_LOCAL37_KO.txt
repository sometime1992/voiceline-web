Local37 배포 전 확인
===================
버전: 2.0.0-local37 / versionCode 52
코드·회귀 검사: 129개 통과 / 실패 0 / 건너뜀 0.

확인
- 현재 박/마디는 왼쪽에만 존재하며 오른쪽 숫자 박 편집기는 기본 화면에서 제거.
- 박자표·BPM 기준·세분·직접 박자·소리·음량·강세 묶음은 기본 화면 내부에 배치.
- 사용자 지정 박자 선택 시 본 화면의 숫자 입력으로 이동하고 박자 자체는 보존.
- 강세·저장 리듬의 두 탭과 키보드 이동/닫기, 본 화면 소리·음량 조절의 앱 연결.
- 재생 중 BPM/음량/음소거/소리 변경 시 현재 박과 마디의 연속성.
- 저장 리듬 생성/복원/페이지/삭제, 이름 중복/잘못된 자료/저장 실패 처리.
- 사용자 지정 1~64박과 분모 조합 유지, 지나치게 빠른 클릭 조합의 거부.
- 기존 녹음 종료/복구/표본 보존/구간 재생/비브라토/음원/워밍업 검사.
- HTML ID 중복, 정적 참조와 접근성 연결 ID, JavaScript 4개 파일 문법.
- CSS 괄호/블록 구조, XML/JSON/PNG, 음원 28개 포함.
- 네이티브 Java·XML·아이콘·MP3 바이트는 Local36과 동일.
- ZIP의 모든 파일을 작업 원본과 비교하고 손상·중복 경로를 검사.

한계
Android SDK APK 빌드, 실제 WebView/브라우저 화면 렌더링 및 휴대폰 오디오는 미확인입니다.
가로 화면의 실제 스크롤 유무와 큰 글꼴·키보드 표시, 스피커/블루투스 출력은 기기에서 확인해야 합니다.
이번 검사는 실제 기기의 가독성·지연에 대한 측정을 대신하지 않습니다.
