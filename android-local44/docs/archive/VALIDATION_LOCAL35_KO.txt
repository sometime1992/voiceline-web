Local35 배포 전 확인
===================
버전 2.0.0-local35 / versionCode 50
코드·동작·회귀 검사: 119개 통과, 실패 0, 건너뜀 0.

변경 범위
- 메트로놈 가로 배치 압축, 템포 카드의 고정 최소 높이 제거, 별도 상세 설정창.
- 탭 템포 제거 및 같은 자리의 메트로놈 켜기/끄기 버튼.
- 화면 폭에 맞춘 박 페이지와 재생 중 현재 박 표시, 수동 편집/페이지 유지.
- 호흡·워밍업 단계/남은 초/다음 단계 및 허밍 시작·종료의 화면·안내음.

검사
- 메트로놈 1~64박의 전체 페이지 접근, 마지막 박 편집/저장, 가로 폭 변경.
- 켜기/끄기 문구와 접근성 상태, 예약 소리 취소, 수동 템포 입력.
- 허밍 시작은 호흡 시작 후 10초, 종료는 16초. 다중 세트와 준비/완료 경계 검사.
- 허밍 두 번 안내음의 시각, 중단/지연 오디오 승인/오디오 중단·복귀 시 예약 처리.
- 기존 녹음·복구·음정·비브라토·음원·오디오 시계 검사를 함께 실행.
- 전체 앱과 메트로놈/워밍업 연결을 가상 DOM에서 실행.
- HTML 중복 ID/정적 참조, CSS 블록/괄호 구조, JavaScript 4개 파일 문법, XML/JSON/PNG 검사.
- MP3 28개와 아이콘/네이티브 Java 소스는 Local34의 바이트를 그대로 유지.
- Android 앱 ID와 기존 데이터베이스·녹음 형식을 유지.
- ZIP 전체 파일을 원본과 바이트 단위로 비교하고 손상·중복·경로를 검사.

한계
실제 브라우저/WebView 렌더링, Android SDK APK 빌드와 휴대폰 스피커·마이크 검사는 미진행입니다.
실기기에서 일반 가로 화면, 큰 글꼴과 키보드 열린 화면을 확인하세요.
