보이스라인 Local36 - 상용 메트로놈 분석 기반 화면·조작 개선
날짜: 2026-10-31
버전: 2.0.0-local36 / versionCode 51

분석 자료
Soundbrenner The Metronome, Pro Metronome(EUMLab), Tempo(Frozen Ape)의 공식 안내를 확인했습니다.
기능 비교와 선택한 설계는 REVIEWS/Metronome_Design_Research_KO.md에 정리했습니다.

반영 내용
1. 가장 큰 숫자는 BPM으로 바꾸고, 빠르기·재생과 현재 박·강세를 좌우로 구분했습니다.
2. 본 화면의 촘촘한 입력 폼을 '박자', '세분', 'BPM 기준' 요약 버튼으로 바꿨습니다.
   밝은 글씨/어두운 면, 통일된 버튼, 구분되는 재생 상태와 강세 색으로 정보 우선순위를 정리했습니다.
3. 현재 마디 표시를 안정적으로 유지합니다. 세분마다 작은 숫자가 빠르게 바뀌는 문구를 없앴습니다.
4. 설정은 '박자 / 소리 / 저장한 리듬' 탭으로 분리했습니다. 탭은 화살표·Home·End로도 이동합니다.
   닫으면 실제로 설정창을 열었던 버튼으로 초점을 돌립니다.
5. BPM 숫자·+/−·슬라이더 변경은 현재 마디를 유지합니다. 슬라이더도 움직이는 동안 바로 반영합니다.
6. 클릭·우드·벨의 3가지 소리와 빠른 음소거를 추가했습니다.
   음량·음소거는 마스터 게인으로 적용해 이미 예약한 박을 지우지 않습니다.
   소리 종류를 바꿔도 박을 다시 시작하지 않습니다. 음량을 올리면 음소거를 해제합니다.
7. 이름을 붙여 리듬 설정을 최대 24개 저장/불러오기/삭제합니다. 두 개씩 페이지로 표시합니다.
   이름 중복과 저장 공간 오류를 안내하며 기존 저장 항목을 조용히 덮어쓰지 않습니다.
   저장 리듬은 메트로놈 설정 즐겨찾기이며 녹음/연습 이력은 생성하지 않습니다.
8. 박자·기준 음표·세분·강세 변경은 새 리듬의 첫 박부터 시작합니다.
9. 사용자 지정 1~64박과 분모 1·2·4·8·16·32·64, 세분 1·2·3·4·6·8은 유지합니다.
   초당 클릭 50회를 넘는 특수 조합은 안내 후 적용하지 않습니다.
10. BPM 20/300 경계에서는 감소/증가 버튼을 비활성화합니다.
11. 탭 템포를 다시 넣지 않았습니다. 메트로놈 켜기/끄기 버튼을 유지합니다.
12. 앱 이탈 시 중지, 기존 녹음/연습 데이터, 호흡·허밍 안내는 유지합니다.
    네이티브 녹음 Java 소스와 MP3/아이콘은 변경하지 않았습니다.

검사
- 기존 검사와 새 메트로놈 검사 총 129개 통과, 실패 0, 건너뜀 0.
- 재생 중 BPM/음량/음소거/소리 변경의 연속성, 저장/불러오기/페이지/삭제, 중복/손상/저장 실패 검사.
- 모든 사용자 지정 박자 조합의 기본 동작, 과도한 클릭 조합의 거부와 기존 설정 보존 검사.
- 전체 앱에서 설정 탭 이동, 메트로놈·워밍업·기록 기능 연결 검사.
- XML/JSON/PNG, JavaScript 문법, 정적 참조, CSS 블록 구조, 배포 ZIP 검사.
- 실제 Android SDK 빌드·마이크·스피커·WebView 렌더링 검사는 미진행입니다.
