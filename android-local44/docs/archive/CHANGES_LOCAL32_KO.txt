보이스라인 Local32 안정성 수정
날짜: 2026-10-31
버전: 2.0.0-local32 / versionCode 47

1. 강약 훈련: 틀린 음정도 분모에 포함합니다. 음정 일치율 65% 이상, 유효 발성 4.8초 이상,
   각 단계 정확한 발성 0.75초 이상, 단계 평균 음량비 1.15배 이상을 함께 확인합니다.
2. 음정 패턴: 회차당 12개 이상 감지, 전체 시간의 40% 이상 발성,
   각 음 길이의 20% 이상 발성이 없으면 정확도 대신 측정 부족으로 기록합니다.
3. 마이크 시작 요청 번호를 JS와 Java에서 함께 확인합니다. 취소·시간 초과·앱 이탈 뒤
   도착한 권한 결과, 이전 요청의 오디오 및 중지 명령은 현재 세션에 적용하지 않습니다.
4. 마이크 입력 오류가 나면 훈련·패턴·비브라토를 중단 처리하고 버튼과 화면 갱신을 복원합니다.
5. 녹음 A→B→A 재생, 일시정지·재개, 늦은 비동기 재생 요청 처리를 수정했습니다.
6. 실제 44.1kHz/16kHz 입력 속도를 시작 응답에 전달하여 WAV 헤더와 녹음 길이를 맞춥니다.
7. 목표음은 검출 범위 C2~A#6 안에서 생성합니다. 높은 기준음에서는 패턴/슬라이드/청음이
   필요에 따라 아래 방향으로 이동하여 측정 불가능한 목표를 내지 않습니다.
8. 네이티브 녹음 세션 정보를 약 2초 단위 오디오 조각과 함께 보관합니다.
   저장 실패 시 나의 기록에서 다시 저장할 수 있습니다. Local32 이후 앱 중단 녹음도
   마지막 보관 구간까지 복구할 수 있습니다. 아직 저장하지 못한 메모리 구간은 앱 종료 시
   사라질 수 있으며 이 경우 화면에 안내합니다. 복구 데이터 삭제에는 별도 확인이 필요합니다.
9. 기록 조회 번호로 오래된 요청을 무시하여 창 재진입 시 목록 중복을 막았습니다.
   목록은 40개씩 불러오며 녹음 Blob/전체 음정 자료는 해당 녹음 재생 시 읽습니다.
10. Android 뒤로가기는 최상단 팝업부터 닫습니다. 마이크 권한 대기 중에는 취소하고,
    녹음·훈련 중에는 먼저 정상 종료합니다. 저장 중에는 완료를 기다립니다.
11. 전체 사용법과 각 모드 설명은 같은 안내 자료를 사용합니다. 기존 설명 버튼 UI를 유지합니다.
12. 웹 서비스 워커가 피아노 엔진과 MP3 28개를 사전 보관하고 다른 앱의 캐시는 삭제하지 않습니다.
    Android 앱은 기존대로 APK 안의 오프라인 자산을 사용합니다.
13. 기록을 삭제할 때 연결된 복구 정보도 한 트랜잭션으로 함께 삭제합니다.
    건반 키보드 접근과 팝업 초점 이동, 앱 이탈 시 녹음 재생 중지도 보완했습니다.

데이터와 설치
- 앱 ID, IndexedDB 이름, 기존 녹음·기록을 유지합니다. 기존 앱을 삭제하지 마세요.
- 같은 PC의 같은 디버그 서명으로 Android Studio에서 업데이트 설치하세요.
- Local31 이전의 입력 정보가 없는 미완료 오디오 조각은 자동 복구 대상에서 제외하며
  자동 삭제하지 않습니다. 기존에 정상 저장된 녹음은 계속 재생할 수 있습니다.
- 파일 내보내기나 서버 전송 기능은 추가하지 않았습니다.

검증
- node --test local_tests/voiceline.test.cjs local_tests/local32.test.cjs local_tests/native_bridge.test.cjs
- 총 69개 통과, 실패 0, 건너뜀 0 (이 작업 환경 기준).

  해당 선택 검사 1개를 건너뛰며 Android Studio 프로젝트 빌드에는 영향을 주지 않습니다.
- 실제 Android APK 빌드 및 기기 마이크/스피커/블루투스와 100/120/150% 글꼴 확인은 별도 필요합니다.
