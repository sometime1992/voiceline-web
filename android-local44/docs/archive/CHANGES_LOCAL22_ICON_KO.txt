VoiceLine Local 22 — 사용자 선택 네온 글래스 앱 아이콘 적용
=======================================================
기준: Local 21 (음정 연습 13종 + 반복하기), 기존 기능 유지.

앱 설치 후 홈 화면에서 표시되는 런처 아이콘을 사용자가 선택한 네온 글래스
마이크·음높이 파형·피아노 이미지로 변경했습니다.
- Android 기본 DPI 5종: mipmap-mdpi ~ xxxhdpi 아이콘
- Android 8.0+ 적응형 아이콘: mipmap-anydpi-v26 + drawable-nodpi
- Android 13+ 테마 아이콘: monochrome 자산 포함
- AndroidManifest.xml application에 icon/roundIcon 지정
- 웹앱 내부 icon-192.png, icon-512.png, favicon.png도 동일 디자인으로 변경
- 설치 앱 표시 이름을 '보이스라인'으로 정리
- 버전: 2.0.0-local22, versionCode 37
- 테스트용 debug applicationIdSuffix '.local18' 유지: 이전 Local18~21 기록 보존 목적

Android Studio: VoiceLine_AndroidStudio 폴더를 열고 Run 'app' 또는 Build APK(s).
GitHub Actions 사용하지 않음. APK는 생성하지 않았음.
원본 이미지는 사용자가 이 대화에서 선택한 아이콘입니다.
주의: 안드로이드 런처의 적응형 마스크에 따라 테두리 일부가 잘릴 수 있습니다.
