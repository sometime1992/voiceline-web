보이스라인 Local39 - 가이드 따라 부르기·녹음 관리와 안정성 개선
날짜: 2026-10-31
버전: 2.0.0-local39 / versionCode 54

1. WAV 헤더에서 손상·누락된 복구 정보를 재구성합니다.
   해석할 수 없는 항목은 오류를 표시하며 원본 파일은 자동 삭제하지 않습니다.
2. 녹음 관리 창에 파일로 저장·공유·이름 변경·삭제를 제공합니다.
   파일로 저장은 시스템 창에서 정한 위치로 스트림 복사하며 복사·닫기 완료 후 성공 표시합니다.
   실패한 외부 복사본은 정리하고, 취소·실패에서도 앱 원본을 보존합니다.
3. 현재 Native WAV와 예전 Blob/WebM/M4A를 모두 원래 형식으로 내보냅니다.
   예전 형식은 최대 64KB씩 임시 복사합니다. 공유는 임시 읽기 권한의 content URI를 사용합니다.
4. 녹음 이름·날짜 검색, MB/GB 용량 표기를 추가했습니다.
   검색 목록은 오디오와 음정 배열 대신 메타데이터만 읽으며 페이지·오래된 요청 처리를 유지합니다.
5. 짧은 녹음의 그래프·재생선·재생 이동 범위와 시간 표기를 실제 길이에 맞췄습니다.
6. 긴 녹음 곡선을 캐시하고 픽셀 단위로 줄였습니다. 무음과 최저·최고 변화는 유지합니다.
   재생 위치선 이동만으로 전체 곡선을 다시 계산하지 않습니다.
7. Native 분석 전송의 대기 수를 JavaScript 실행 완료까지 최대 3개로 제한합니다.
   오디오 파일 저장은 분석 전송과 독립적으로 이어집니다.
8. 녹음 화면에 저장 여유와 WAV 기준 예상 시간을 표시합니다.
   녹음 진행 중 파일 내보내기로 앱이 이동하여 녹음이 중단되는 일을 막습니다.
9. 호흡·워밍업 단계별 시간·안내음 설정을 추가했습니다.
   기본 4/6/6/3초를 유지하며 단계·소리·진행 시간·결과가 같은 시간표를 참조합니다.
10. 예비 피아노를 포함된 MP3로 통일하고 음원 상태 표시 충돌을 수정했습니다.
    오래된 OGG 경로·보정표·미사용 상태값·도달하지 않는 워밍업 그래프를 제거했습니다.
11. 그래프·파일 전달 모듈과 새 설정 스타일을 분리했습니다.
    이전 변경/검사 문서는 docs/archive로 옮기고 현재 사용 안내를 정리했습니다.
12. 기존 연속 녹음·기록 구분·복구 호환과 Local38 메트로놈의 화면·조작을 유지합니다.
13. 가이드 따라 부르기 모드를 추가했습니다.
    한 구절 듣기 → 0.8초 준비 → 같은 구절 따라 부르기 → 쉬기 순서입니다.
    10가지 패턴, 피아노·허밍 톤·모음 톤, 시작음·빠르기·반복·반음 이동을 선택합니다.
    가이드 구간은 채점하지 않고 따라 부를 때 목표 음정선과 실제 목소리를 겹쳐 표시합니다.
    음정 차이·시간 기준 일치율·발성 커버리지·더 연습할 음을 보여줍니다.
    음 시작 0.1초를 제외하고 전체·각 음의 발성 시간을 확인하여 일부만 부른 성공을 막습니다.
    설정은 별도 창으로 옮겨 가로 주 화면을 그래프에 사용합니다.
    예약 소리는 중단·앱 이탈·오디오 중단에서 취소하고 결과는 연습 기록에만 남깁니다.
    영상·가수의 음성은 포함하지 않습니다. 허밍·모음 톤은 합성 안내음입니다.
