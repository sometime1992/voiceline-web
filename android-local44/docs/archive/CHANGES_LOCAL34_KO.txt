보이스라인 Local34 - 추가 점검 7개 보완 및 독립 메트로놈
날짜: 2026-10-31
버전: 2.0.0-local34 / versionCode 49

1. 녹음 종료 완료 확인
- 네이티브 캡처가 진행 중인 마지막 읽기까지 WAV에 쓴 뒤 파일을 닫고 완료 응답합니다.
- JS는 완료 응답까지 녹음 세션과 요청 ID를 유지합니다. 마지막 음정 자료도 그때 확정합니다.
- 시작 취소/오래된 응답 차단과 정상 녹음 종료를 구분합니다. 종료 요청은 반복해도 같은 파일입니다.
- 실제 백그라운드 전환에서도 네이티브가 파일을 끝냅니다. 앱이 강제 종료된 파일은 복구 대상입니다.

2. 복구 저장 보호
- 최초 저장과 다시 저장 모두 전역 저장 상태에 포함합니다. 완료 전 뒤로가기로 앱이 종료되지 않습니다.
- 성공·실패 시 상태를 해제하고 저장 실패한 파일/자료는 재시도할 수 있게 보존합니다.

3. 녹음·그래프 시간 기준
- 각 네이티브 분석 묶음에 누적 수집 표본 위치를 함께 전달합니다.
- 녹음 음정 점은 시작 표본 기준의 상대 시간, 길이는 실제 저장 표본 수로 계산합니다.
- 늦게 처리된 음정의 위치가 JS 대기 시간만큼 밀리지 않게 했습니다.
- 녹음 시작 전에 수집된 대기 분석 묶음은 새 녹음 그래프에 넣지 않습니다.

4. 비브라토 연속성·최근성
- 무음·기준음 이탈·160ms를 넘는 입력 공백마다 연속 구간을 나눕니다.
- 한 연속 구간 안에서 주기 4개가 연속으로 중앙값 ±35% 조건을 충족해야 합니다.
- 최근 유효 입력이 끊기면 현재 속도/진폭 표시를 비우고 재측정을 안내합니다.
- 최종 연습 기록에 전체 시간, 실제 유효 측정 시간, 마지막 유효 측정의 경과 시간을 구분합니다.

5. 피아노 실패·재시도
- 음원 준비/완료/실패 상태를 구분하며 20초 준비 시간 제한을 적용합니다.
- 실패 및 준비 중에는 기존 예비 음색 경로로 건반과 기준음을 재생합니다.
- 음원 오류 시 건반 위에 재시도 버튼을 표시합니다. 늦은 이전 요청이 새 음원을 덮지 않습니다.

6. 긴 녹음 저장
- 새 Android 브리지는 오디오를 JS 배열/IndexedDB 임시 조각에 쌓지 않고 하나의 WAV에 순서대로 씁니다.
- 오디오 파일 수는 녹음 1회당 1개입니다. 무음 감지에 따른 중지·분할이나 10분 제한이 없습니다.
- 화면 분석용 전달 대기는 최대 3묶음으로 제한합니다. 화면이 늦으면 분석점은 생략할 수 있지만
  네이티브 파일 쓰기는 모든 읽은 오디오 표본을 계속 보관합니다.
- 음정 복구 자료는 새 점만 추가합니다. 전체 음정 배열을 매 2초 다시 복사하지 않습니다.
- 최종 오디오 Blob 복사 없이 내부 HTTPS 경로로 재생하며 바이트 구간 응답으로 탐색합니다.
- 미완료 파일은 저장된 표본 길이로 WAV 헤더를 복구합니다. DB 저장 후에만 완료 상태로 바꿉니다.
- 완료된 파일은 복구 목록 탐색에서 제외합니다. 오디오/기록은 기기 밖으로 전송하지 않습니다.
- 기존 웹·구형 네이티브 경로는 호환용으로 유지합니다. 파일 직접 쓰기는 새 Android 경로입니다.

7. 기록 목록 조회
- 기존 DB를 버전 4로 업그레이드하며 recordingsMeta에 작은 목록 정보만 추가합니다.
- 기존 오디오/음정 자료는 변경하지 않습니다. 새 저장은 본문·목록 메타데이터가 함께 커밋됩니다.
- 목록은 메타데이터만 40개씩 읽고 재생 때 전체 음정/음성을 읽습니다.
- 삭제도 본문·메타데이터·파일 정리 요청을 함께 커밋합니다. 파일 정리는 실패 시 다음에 재시도합니다.

8. 메트로놈
- 메뉴에 독립 메트로놈을 추가했습니다. 마이크, 녹음, 연습 이력 없이 사용할 수 있습니다.
- 기본 박자표 19개 및 사용자 지정 1~64박 / 분모 1·2·4·8·16·32·64를 지원합니다.
- 20~300 BPM, 숫자·슬라이더·+/−·탭 템포로 빠르기를 조절합니다.
- 박자표 1박·4분음표·점4분음표 중 BPM 기준을 선택합니다. 복합박자 속도를 명확히 표시합니다.
- 세분 1·2·3·4·6·8, 각 박 강세/보통/묵음, 2+2+3 같은 강세 묶음을 설정합니다.
- 피아노와 별도 음량, 음량 0일 때 시각 박자, 마디/박 점등과 설정 보관을 지원합니다.
- 오디오 시계에 클릭을 미리 예약합니다. 화면 지연 후 밀린 클릭을 몰아서 재생하지 않습니다.
- 중지/모드 이동/백그라운드에서 예약된 소리도 취소합니다.

검증
- 코드/회귀 검사 총 107개 통과, 실패 0, 건너뜀 0.
- 네이티브 마지막 읽기·콜백 순서, WAV의 시작/무음/끝 보존, 헤더 복구·구간 재생·경로 검증.
- 가상 지연 입력의 그래프 동기화, 복구 중 뒤로가기, 원자적 메타데이터 저장, 비브라토 오검출.
- 음원 실패/시간 초과/재시도, 전체 앱과 메트로놈 설정 실행, 모든 사용자 지정 박자 조합·타이밍.
- XML/JSON/정적 파일 참조와 기존 MP3/아이콘 보존 및 배포 ZIP 검사를 별도로 수행했습니다.
- Android SDK APK 빌드, 실제 마이크 녹음/재생, 스피커·블루투스 지연과 글꼴 확대는 실기기 미확인입니다.
