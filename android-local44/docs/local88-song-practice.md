# VoiceLine Local88 — 원곡 연습 UI·오디오 제어 개선

기준: VoiceLine Local87 (build/android-apk). 기존 피아노·녹음·비브라토·메트로놈·연습 루틴·영어 설정·저장 기록 유지.

## 사용자 경험
- 메뉴의 '원곡 따라 부르기'를 선택하면 기존 건반 위의 반투명 그래프에 기준선(민트)과 내 음정(보라)을 표시합니다.
- 상단 ① 원곡 선택 → ② 피치 분석 → ③ 마이크+노래 시작 순서로 안내하고 최초 진입 시 사용법을 자동으로 엽니다.
- 하단의 Naruvium Studio YouTube 아이콘은 채널 연결로만 사용하며 외부 앱/브라우저에서 열립니다.
- ⚙ 설정에서 사용자가 직접 갖고 있는 MR과 분리 보컬 파일을 선택할 수 있습니다. 동기화 시간 보정, 기준 그래프 반음 이동(오디오 자체의 키 변경 아님), 구간 반복이 지원됩니다.

## 오디오·저장
- Android에서는 사용자 선택 파일(content://)만 MediaPlayer로 열고 기존 AudioSessionGuard를 네이티브 마이크와 공유합니다. 웹 브라우저는 HTML audio fallback.
- 원곡/MR은 서버에 업로드하지 않고 로컬에서만 재생합니다. 피치 분석 결과만 별도 IndexedDB에 보관합니다.
- 혼합 원곡에서 단일 YIN 피치 검출은 음반의 보컬 멜로디를 보장하지 않습니다. 그런 경우 참고용 회색 선만 표시하며 점수는 부여하지 않습니다. 사용자가 분리한 보컬 파일을 넣어야 민트색 기준과 ±50cent 참고 일치율을 표시합니다.
- **중요:** AI 보컬 자동 분리, 자동 MR 생성 기능은 포함하지 않습니다. 정확한 권리·모델 라이선스를 검토한 뒤 별도 개발이 필요합니다.
- 음악 재생·마이크 동시 작동은 실제 Android 기기 테스트가 필요합니다.

## 저작권 안내
이 앱은 보컬/음악 파일을 직접 배포하거나 스트리밍 서비스를 추출하지 않습니다. 이용 권한이 있는 파일만 사용하도록 안내합니다. 로컬 처리·비저장만으로 모든 저작권 문제를 면책할 수 없습니다. 상용 모델 학습 가중치는 코드 라이선스 외 별도 확인이 필요합니다.
