# VoiceLine MR + 악보 기반 피치 어드바이저 — 설계 제안

## 목표
개발자는 MR/원곡/악보를 제공하거나 생성하지 않고, 사용자가 권리를 확인한 로컬 MR과 악보를 불러와 모바일 기기 안에서만 연습한다.
앱은 오프라인 MR 재생, 악보 기준 피치 그래프, 마이크 피치 측정과 차이(cent), 구간 반복, 보컬 연습 안내만 제공한다.
앱 자체에서 음원 분리, MR 추출, DRM 해제, 스트리밍 서비스 리핑, 음원 공유·내보내기, 믹스다운을 제공하지 않는다.

## 권장 입력
- MR: 사용자가 직접 보유한 로컬 MP3, WAV 등 DRM 없는 파일. 원음원이나 MR의 사용 허락 여부는 파일 선택 전 안내한다.
- 악보: MusicXML (.musicxml, .xml) 우선 지원. 음정·박자·템포·길이·보컬 파트·(있는 경우) 음절을 구조적으로 읽는다. MIDI (.mid/.midi)도 지원 가능하지만 가사·파트 표기와 악보 표기가 빈약할 수 있다.
- PDF/악보 사진: 표준 피치 정보가 없다. OCR/OMR에 의존하므로 별도 선택적 기능으로 개발하고 정확도 검증이 필요하다.
- 사용자 파일 자체는 영구 보관하지 않고 메모리/일시적 URI로만 처리한다. 자동 악보 추출 또는 코드 공유 없음.

## 동기화 및 정확성
- 악보의 음정은 MR의 다성음 분석으로 추정하지 않는다. 선택한 악보의 성악 파트에서 기준 음정을 구한다.
- MR의 전주·템포·반복·루바토 때문에 자동으로 시간축이 일치하지 않을 수 있어 시작 시간 오프셋, BPM/템포 맵, 구간별 수동 동기화를 제공한다.
- MIDI 다중 트랙 또는 MusicXML 다중 파트에서 사용자가 멜로디 파트를 선택한다.
- 한 음에 여러 가사 음절, 한 음절에 여러 음, 멜리스마·쉼표·타이 등을 파싱한다.
- 피치 그래프는 기존 VoiceLine 피아노 건반 위에 표시. 민트색=악보 기준, 보라색=사용자 음정. 불확실한 구간을 임의로 메우지 않는다.
- 그래프만으로 악보를 사실상 재배포할 수 있는 내보내기, MIDI 내보내기, 전체 악보 화면 캡처 기능을 앱에 별도로 제공하지 않는다.

## 사용법 UX
1. MR 선택 → 2. 악보 선택 → 3. 보컬 파트 선택 → 4. 전주/박자 정렬 → 5. 이어폰으로 MR+실시간 마이크 함께 연습.
최초 실행 시 예시(권리 확보된 자작 짧은 연습곡), 도움말, 차이(센트), 기기 미지원 시 안내한다.

## 권리·개인정보
- 오디오나 악보를 서버로 전송하지 않고 세션 내에서만 처리. 악보 노트 및 파생 멜로디 정보는 세션 종료 시 삭제. 이전 Local87/88의 song-reference 전용 IndexedDB 캐시만 정리하며 기존 사용자 녹음·연습 기록 데이터베이스는 건드리지 않는다.
- 사용자가 파일을 제공하는 구조는 위험을 낮추지만, 구매·보유 사실만으로 이용 허락을 대체하거나 개발자에게 무조건적인 법적 면책을 주지는 않는다.
- 이용약관에 이용 권한 확인과 권리침해 금지, 오프라인 임시 처리, 비저장·비공유를 명확히 표시하고 상용 출시 전 지식재산권 법률 검토 권장.

## 개발 상태
이 문서는 **설계안**이며, MusicXML/MIDI 입력·MR 동기화·악보 기준 그래프는 현재 배포된 Local88에서 아직 구현되지 않았다.
현재 Local88은 원곡 혼합음에 YIN 추정치 또는 사용자가 선택한 분리 보컬을 입력받는 기존 방식이다.
이를 악보 기반으로 완전히 전환하려면 별도의 기능 구현과 실기기 테스트가 필요하다.
